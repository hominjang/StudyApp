# 학습 앱 목적과 범위

사용자가 선택한 질문–답 데이터를 읽고 시험으로 이해를 확인한다. 기초 용어부터 익히고 단답과 설명을 통해 학습하며, 주제에 관계없이 공통 데이터 구조로 표현한 자료를 사용할 수 있게 한다.

## 우선 구현 범위

- 학습할 데이터를 선택하고 문제를 출제한다.
- 시험 없이 질문과 답을 함께 읽는 자료 학습을 제공한다. 읽기만으로 시험·평가·오답 기록을 바꾸지 않는다.
- 짧은 정답 문자열과 완전히 일치하는지 자동 채점하고 틀린 문항을 확인할 수 있게 한다.
- 제출 답변과 문항별 결과를 저장한다.
- 진행 중인 시험을 자동 저장하고, 중단 후 이어 풀기를 지원한다.
- 다음 시험에서는 이전 학습 기록을 반영해 문제를 출제한다.

## 확장 방향

기초 용어 문항과 서술형, 사용자 평가·부분정답·정정으로 확장한다. Windows의 기존 DB 1은 단답형, 신규 DB 2는 혼합 학습을 지원한다. 새 기능의 순서와 미정 기준은 [확장 계획](../작업계획/05_학습방식확장계획.md)에서 관리한다.
