# 학습 앱 데이터 구성

학습 자료와 사용자의 학습 결과를 분리하고, 문항의 식별자를 통해 연결한다.

| 구성 | 역할과 관계 |
| --- | --- |
| 데이터 묶음 | 사용자가 선택하는 학습 자료이며 여러 문항을 포함한다. |
| 문항 | 고유 ID로 식별하는 질문과 유형별 평가 기준. 단답형 정답 표기와 서술형 참고 답안·핵심 내용을 구분한다. |
| 보충 정보 | 문항에 연결되는 선택 정보로, 설명·예시·주의점·분류·출처 등을 담는다. |
| 학습 기록 | 사용자별 진행 상태·제출 답변·평가와 정정 이력을 보관해 이어 풀기와 이후 출제에 활용한다. |

## 데이터 설계 기준

- 문항 유형에 맞는 기준을 문항 본체에 두고, 추가 해설·예시는 보충 정보로 분리한다.
- 문항의 의미가 유지되는 문구 수정에는 기존 식별자를 유지한다.
- 보충 정보가 없어도 질문–답만으로 학습할 수 있게 한다.
- 같은 학습 데이터를 여러 시험과 학습 방식에서 재사용한다.
- 데이터와 기록은 특정 화면이나 저장 방식에 종속되지 않게 한다.

서술형·선행 용어 연결·평가 이력은 확장 목표이며 현재 JSON 1.0과 앱은 단답형만 지원한다. 새 구성은 [확장 계획](../작업계획/05_학습방식확장계획.md)에서 구체화한다.

## 검증 자료

초기 출제 자료는 [Android 107문항과 일반 CS 147문항](../../data/initial/README.md) 두 묶음이다. 출제용 데이터와 보충 정보의 경로는 [초기 자료 목록](../../data/initial/catalog.json)으로 관리한다.

설명형 원문과 [22문항 파일럿](../../data/android-cs/pilot-01/README.md)은 변환 검토 이력으로 보관한다. 최종 필드와 저장 구조는 데이터 상세 설계에서 정의한다.
