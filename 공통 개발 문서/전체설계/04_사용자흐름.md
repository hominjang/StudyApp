# 학습 앱 사용자 흐름

사용자는 선택한 자료의 질문·답을 함께 읽거나 시험을 풀고 결과를 확인한다. 자료를 읽기만 할 때는 기록을 바꾸지 않으며, 저장된 시험·평가 기록은 다음 출제에 반영한다.

1. 질문–답 데이터를 준비한다.
2. 학습할 데이터와 대상을 선택한다.
3. 선택한 대상과 기존 학습 기록을 바탕으로 시험을 출제한다.
4. 한 문항씩 표시하고 번호 목록으로 이동하며 유형에 맞게 답변을 작성한다. 진행 상태는 자동 저장하고, 중단한 시험은 이어 풀 수 있다.
5. 시험을 최종 제출한다. 미응답이 있으면 안내하고 제출 여부를 선택한다.
6. 단답형은 완전 일치 자동 채점한다. 확장할 서술형은 제출 후 참고 답안과 핵심 내용을 보고 사용자가 평가한다.
7. 제출 답변과 평가를 기록하고 결과를 확인한다. 확장할 회고 기능에서는 답변 원문을 보존하며 평가를 정정한다.
8. 다시 학습할 때 저장된 기록을 반영해 시험을 출제한다.

화면 간 이동은 [화면 연결](../../Window/화면흐름/00_화면연결.md), 자동 채점과 재출제 기준은 학습 규칙 상세 설계에서 정의한다.

Windows의 기존 DB 1은 단답형, 신규 DB 2는 서술형·평가 대기·정정과 기초 복습도 지원한다. 자료 학습은 두 저장소에서 사용할 수 있다. 기존 DB 전환과 확장 후속 범위는 [확장 계획](../작업계획/05_학습방식확장계획.md)을 따른다.
