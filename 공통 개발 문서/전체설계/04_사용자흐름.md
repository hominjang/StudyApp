# 학습 앱 사용자 흐름

사용자는 선택한 자료로 시험을 풀고 결과를 확인한다. 저장된 학습 기록은 다음 시험의 출제에 반영한다.

1. 질문–답 데이터를 준비한다.
2. 학습할 데이터와 대상을 선택한다.
3. 선택한 대상과 기존 학습 기록을 바탕으로 시험을 출제한다.
4. 한 문항씩 표시하고 번호 목록으로 이동하며 단답이나 짧은 문장 답변을 작성한다. 진행 상태는 자동 저장하고, 중단한 시험은 이어 풀 수 있다.
5. 시험을 최종 제출한다. 미응답이 있으면 안내하고 제출 여부를 선택한다.
6. 정답 문자열과 완전히 일치하는지 자동 채점하며, 제출된 미응답은 오답으로 처리한다.
7. 제출 답변과 결과를 기록하고, 모범 답변과 문항별 결과를 한 번에 확인한다.
8. 다시 학습할 때 저장된 기록을 반영해 시험을 출제한다.

화면 간 이동은 [화면 연결](../../Window/화면흐름/00_화면연결.md), 자동 채점과 재출제 기준은 학습 규칙 상세 설계에서 정의한다.
