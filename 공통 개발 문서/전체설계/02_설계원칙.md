# 학습 앱 설계 원칙

문제 풀이와 결과 확인이 다음 학습으로 이어지도록 앱 전반을 설계한다.

- **학습 목표 중심:** 기능은 문제를 풀고, 부족한 부분을 확인하고, 다시 학습하는 데 도움이 되도록 구성한다.
- **학습 기록의 연속성:** 답변과 평가 결과를 보존하고, 다음 시험에서도 누적된 기록을 활용한다.
- **명확한 사용 흐름:** 사용자가 현재 할 일과 학습 결과를 쉽게 파악할 수 있게 한다.
- **학습 주제의 독립성:** 특정 과목에 기능을 고정하지 않고, 선택한 질문–답 자료로 학습할 수 있게 한다.
- **시스템 책임의 분리:** 화면, 학습 처리, 데이터 관리의 역할을 구분해 각 영역의 변경 영향을 줄인다.
- **단계적인 구체화:** 전체 설계는 방향과 원칙을 간결하게 정하고, 필요한 영역부터 상세 설계를 구체화한다.

- **실제 데이터의 분리:** 실제 학습 자료와 사용자 기록은 로컬로 보관하고 Git에 올리지 않는다. 구체적인 범위는 [데이터와 Git 관리 원칙](../개발원칙/01_실제데이터와Git관리.md)을 따른다.
