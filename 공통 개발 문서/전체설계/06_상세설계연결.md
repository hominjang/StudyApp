# 학습 앱 상세 설계 연결

공통 상세 설계는 목적과 원칙을 데이터 형식과 학습 동작으로 연결한다. 플랫폼별 구현 문서는 이를 해당 환경의 코드와 화면·저장소에 연결한다.

| 구분 | 정의할 내용 |
| --- | --- |
| [공통 데이터](../상세설계/데이터/README.md) | 자료·기록 구조와 식별, 자료 변환·검증 |
| [공통 학습 규칙](../상세설계/학습규칙/README.md) | 출제·채점·진행 보존과 이전 기록 반영 |
| [공통 개발 원칙](../개발원칙/README.md) | 실제 데이터와 Git의 분리 등 관리 기준 |
| [Android 문서](../../Android/README.md) | Android의 구현 계획·기술·화면·저장소 연결 |
| [Window 문서](../../Window/README.md) | Windows의 구현 계획·기술·화면·저장소 연결 |

작업 상태는 [공통 설계 진행 계획](../작업계획/01_설계진행계획.md)과 각 플랫폼의 작업 계획에서 확인한다. 세부 내용은 주제별 문서에 작성하고 README에는 찾을 내용과 경로만 안내한다. 문서를 이동하거나 추가하면 관련 목차와 참조를 함께 갱신한다.
