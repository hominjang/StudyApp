# 학습 앱 시스템 구성

시스템은 화면, 학습 처리, 데이터 관리로 책임을 나눈다. 각 영역은 정해진 역할을 통해 연결한다.

| 영역 | 책임 |
| --- | --- |
| 화면 | 학습 자료 선택, 시험 진행, 결과와 기록 확인을 제공하고 사용자 입력을 전달한다. |
| 학습 처리 | 문제를 선택하고 답변을 평가하며, 이전 학습 기록을 출제에 반영한다. |
| 데이터 관리 | 학습 데이터와 사용자 학습 기록을 각각 저장하고 조회한다. |

화면에서 전달한 요청을 학습 처리가 수행하고, 필요한 데이터와 기록은 데이터 관리를 통해 조회·저장한다. 처리 결과는 화면에서 표시한다.

자료 교환은 공통 JSON 형식을 사용한다. 실행 중 저장소와 연결 방식은 [Android](../../Android/README.md)와 [Window](../../Window/README.md)의 플랫폼별 설계에서 정한다.
