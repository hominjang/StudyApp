# 프로젝트 작업 현황

최종 갱신: 2026-11-27. 현재 작업 트리의 코드와 수행 기록을 기준으로 정리했다.

현재 Windows 앱은 기존 DB 1 학습을 유지하고, 신규 DB 2에서 혼합 시험·사용자 평가/정정·기초 문항 수동 복습을 지원한다. 배포 exe에 자료 추가·갱신 기능을 포함했다. 기존 DB 1은 JSON 1.0만 가져오고 DB 2는 1.0/2.0을 가져온다. 실제 사용자 DB 활성 전환·실제 자료 보강은 하지 않았다. [혼합 시험 결과](../../Window/작업계획/17_혼합시험과평가화면.md)·[자료 추가 결과와 실행 파일](../../Window/작업계획/18_배포앱자료추가.md)

두 저장소에서 시험 없이 현재 질문·답을 함께 읽는 **자료 학습**을 추가했다. 자료별 선택·질문 검색·페이지 이동을 지원하며 시험·평가·오답 기록은 바꾸지 않는다. [자료 학습 결과와 실행 파일](../../Window/작업계획/19_질문답자료학습.md)

메뉴를 **자료 학습 → 시험 시작 → 시험 기록 → 자료 추가**로 정리하고 자료 학습의 정답·해설 편집을 추가했다. 자료 수정은 새 시험에 반영하며 기존 시험/오답 기록은 유지한다. [메뉴·편집·버튼 통일 결과](../../Window/작업계획/20_메뉴와자료편집.md)

## Windows에서 현재 사용할 수 있는 기능

- 로컬 초기 JSON의 형식·ID·정답 표기·연결 관계를 검증하고 SQLite에 등록한다.
- 초기 자료와 로컬 프로필 하나를 함께 저장하고, 재실행해도 중복 등록 없이 유지한다.
- 자료별 문항 수를 확인하고, 하나 이상의 자료를 선택·해제하거나 선택 순서를 바꾼다.
- **자료 학습**에서 전체/자료 하나의 질문·답·허용 표기·참고 답안/핵심 내용·해설을 함께 읽고 질문 검색·페이지 이동을 한다. 읽음 기록이나 시험/오답 상태 변경은 없다.
- 일반·오답 우선·오답만, 문제 수·전체 출제·표시 순서를 선택해 시험을 시작하고 한 문항씩 풀거나 번호 목록으로 이동한다.
- 최종 제출에서 미응답을 안내하고, 전체 제출 후 완전 일치 채점 결과와 정답·허용 표기를 공개한다.
- 답변·채점·완료 상태·현재 문항 학습 상태를 저장하고 결과의 전체·오답·미응답 필터와 공백 표시를 제공한다.
- 답변·위치를 자동 저장하고 정상 창 종료 전에 최신 저장을 기다린다. 저장 실패 시 창과 입력을 유지한다.
- 미완료 시험 목록에서 같은 문항·순서·답변·위치로 이어 풀거나 제출 후 처리를 재개한다.
- 시험 기록을 상태별로 조회하고, 과거 결과에서 같은 설정 또는 현재 오답 대상으로 새 시험을 준비한다.
- 오답 뒤 3회 연속 정답이면 오답 대상에서 제외하고, 중간 오답이면 횟수를 초기화한다. 과거 판정과 현재 학습 상태를 구분한다.
- 초기화 오류를 안내하고 자료 준비 후 재시도한다. 손상되거나 지원하지 않는 기존 DB를 초기 자료로 덮어쓰지 않는다.

자료 가져오기·갱신 미리보기·적용을 구현했고 기존 시험·답변·학습 상태를 보존한다. 사용 방법은 [자료 추가 안내](../../Window/사용안내/01_문제자료추가.md)를 따른다. 내보내기·독립 복제·백업·복구는 아직 구현하지 않았다. 강제 종료 시에는 마지막 COMMIT까지만 복원한다. 브라우저는 화면 미리보기이며 실제 SQLite 연결은 Windows 앱에서 사용한다.

서술형·미평가·부분정답·평가 정정과 선행 용어 연결은 신규 DB 2와 새 exe에서 가상 검증한 구현이다. 기존 DB 1은 단답형으로 유지하며 자동 전환하지 않는다. 기존 실제 자료 254문항은 재작성하지 않았다. 미확정 정책을 사용자 확정으로 기록하지 않으며, 실제 확장 적용 전 점검은 남아 있다.

개발 실행 명령과 DB 위치는 [자료 연결 결과의 실행 방법](../../Window/작업계획/07_자료등록과저장소연결.md#실행-방법)을 따른다. 개발 서버 없이 실행할 Windows x64 exe 폴더는 [실행 파일 안내](../../Window/작업계획/11_Windows실행파일.md)를 따른다. 설치 프로그램·서명·다른 PC의 배포 환경 검증은 남아 있다.

## 저장소와 현황 관리

1~5단계 코드와 문서는 `b347da6`에 커밋했다. 2026-11-27 후속 커밋은 Windows 실행 파일 생성 명령·기존 답변 복원·혼합 시험과 사용자 평가·자료 추가/갱신·질문과 답 읽기·정답/해설 편집·메뉴/버튼 정리 및 관련 설계·검증 문서를 함께 보관한다.

구현 검증은 Rust 120개·화면 32개와 TypeScript/Vite 빌드 통과 기록을 따른다. 커밋 전에는 문서 경로와 실제 데이터 Git 제외 및 stage 내용을 다시 검사한다. 실제 자료·사용자 DB·빌드/배포 exe는 제외하고 별도 `상세설계.zip`도 커밋 대상에 넣지 않는다. 새 실행 폴더와 이전 실행 폴더는 로컬에 유지한다. push는 별도 요청에 따른다.

작업 단계가 끝나거나 범위가 바뀌면 이 문서의 갱신일·현재 기능·다음 작업을 함께 수정한다. 상세 구현·검증 이력은 플랫폼의 작업 결과 문서에 남기고, 이 문서는 요약과 경로를 유지한다.
