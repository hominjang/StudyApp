# 공통 초기 설계 결정

사용자가 정한 학습 요구와 공통 데이터 기준을 관리한다. 플랫폼별 UI 기술과 저장소 연결 및 화면 기본값은 각 플랫폼에서 정한다.

| 항목 | 공통 기준 | 경로 |
| --- | --- | --- |
| 자료 선택과 출제 | 한 개 이상 묶음, 지정 수 또는 전체, 무작위 또는 순서대로 | [출제](../상세설계/학습규칙/01_출제.md) |
| 정답 표기 | 대표 정답 하나와 선택적인 허용 표기. 각 표기는 4단어 이하이며, 넘으면 가져오기에서 거부 | [학습 데이터](../상세설계/데이터/01_학습데이터.md), [문항 작성](../상세설계/데이터/04_단답형문항작성.md) |
| 채점과 공개 | 문자열 완전 일치, 최종 제출 후 일괄 공개 | [자동 채점](../상세설계/학습규칙/02_1_자동채점기준.md) |
| 미응답과 원문 | 빈 답과 Unicode `White_Space` 25자로만 된 답은 안내 후 오답. 입력 원문 보존 | [자동 채점](../상세설계/학습규칙/02_1_자동채점기준.md), [문항별 응답](../상세설계/데이터/02_2_문항별응답.md) |
| 식별자 형식 | 자료·문항 ID는 소문자 영문·숫자·하이픈 1~64자. 앱이 만드는 ID는 소문자 UUID v4 | [식별과 관계](../상세설계/데이터/03_식별과관계.md) |
| 진행 보존 | 진행 중 자동 저장과 중단 후 이어 풀기 | [진행 저장과 재개](../상세설계/학습규칙/03_1_진행저장과재개.md) |
| 기록 반영 모드 | 일반·오답 우선·오답만 선택 | [재출제](../상세설계/학습규칙/04_재출제.md) |
| 오답 해제 | 오답 이후 3회 연속 정답, 중간 오답 시 횟수 초기화 | [오답 대상](../상세설계/학습규칙/04_1_오답대상관리.md) |
| 기록 적용 순서 | 완료 순번 기준으로 같은 결과를 한 번만 반영 | [학습 상태](../상세설계/데이터/02_3_문항학습상태.md) |
| 자료 교환 형식 | 질문·정답과 선택 보충 정보를 분리한 JSON 1.0 | [데이터 목차](../상세설계/데이터/README.md) |
| 실제 자료 관리 | 로컬 폴더로 분리하고 Git에 업로드하지 않음 | [Git 관리 원칙](../개발원칙/01_실제데이터와Git관리.md) |

공백뿐인 답을 미응답으로 식별하는 공백 문자 목록과 ID 형식(2026-11-24 결정), 정답 표기의 4단어 상한(2026-11-26 결정), 완료 순번·교환 버전은 사용자 요구를 구현하기 위해 선택한 공통 설계 기준이다. 명시된 요구와 세부 설계 선택을 구분하며 관련 문서를 함께 갱신한다.

Windows 기본값·저장 간격·로컬 프로필·기록 수정과 삭제 범위 및 기술 선택은 [Window 초기 구현 결정](../../Window/작업계획/03_초기구현결정.md)에 분리했다. Android의 구현 계획은 아직 작성 전이다.
