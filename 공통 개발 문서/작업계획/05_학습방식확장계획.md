# 기초 용어·서술형·사용자 평가 확장 계획

작성일: 2026-11-26. 수정일: 2026-11-27. 상태: 확장 2/3의 DB 2 시험·평가/정정·기초 복습 UI 구현과 가상 Windows 검증 완료. 정책 최종 점검·실제 사용자 DB 전환·자료 보강·배포는 남음.

## 목적과 범위

질문에 나오는 용어부터 익히고, 용어를 떠올리는 학습과 자기 말로 설명하는 학습을 함께 지원한다. 기존 단답형 자동 채점은 유지하고 서술형 답변 저장·사용자 평가·부분정답·평가 정정을 추가한다. 제출 답변과 원래 평가를 보존하며 현재 평가와 다음 출제 상태를 연결한다.

| --- | --- |

2026-11-26에 사용자가 추천안을 채택해 서술형 참고 답안의 4단어 제한 제외와 초기 평가의 개수 표시를 확정했다. 숫자 배점·부분정답의 점수 환산·혼합 합계는 이번 초기 확장 범위에 넣지 않는다. 정확한 데이터 필드·버전·상태는 아래 단계에서 정의한다. 용어 연결은 학습 안내이며 선수 문항을 맞힐 때까지 다른 문항을 잠그는 기능은 이번 범위에 넣지 않는다. 범용 자동 문항 생성기·AI 의미 채점·여러 사용자 서비스도 이번 계획에 포함하지 않는다.

## 진행 순서와 산출물

후속 [목록 격리·평가 명령](../../Window/작업계획/16_손상기록과평가명령.md)에서 기본 열 손상과 DB 2 평가/수동 복습·원자적 재계산을 가상 검증했다. 확장 3은 DB 2 시험 저장소·혼합 UI까지 가상 Windows 검증했고 기존 사용자 DB 활성 전환은 아직 적용하지 않았다. 미정 정책을 사용자 확정으로 올리지 않는다.

| 순서 | 작업 | 산출물과 완료 기준 | 상태 |
| --- | --- | --- | --- |
| 확장 1 | 문항과 평가 정책 검토 | 기초 문항 접근 경로, 기초→이해→응용 작성 기준, 평가 상태의 구분·완료 순번 부여 시점, 부분정답·미평가·정정의 집계 정책 확정 | 기초 문항의 수동 편입·서술형 길이·초기 평가 개수 표시 확정. 나머지 세부 정책 검토 중 |
| 확장 2 | 데이터·기록·호환 설계 | 새 교환 형식, 유형별 필수 값, 선행 연결 저장 위치, 출제 기준과 평가 이력, DB 전환·원자적 저장·재계산의 손상 행 정책 작성. 가상 자료로 구형 호환과 실패 경로 검증 | [자료 형식](../상세설계/데이터/06_확장자료교환형식.md)·[연결 설계](../../Window/구현설계/확장/README.md) 초안과 [파서/사본 전환 기반](../../Window/작업계획/15_확장파서와전환기반.md) 구현·가상 검증 완료. 목록 격리·DB 2 평가/복습 명령 검증 완료. 확장 2에서는 앞선 검토의 기본 열 읽기 단계까지 포함한 손상 기록 격리와 후속 시험 완료의 재계산 정책을 설계하고 보완한다. 손상 행을 전체 차단할지, 해당 문항만 오류로 다룰지, 표시 후 제외할지는 명시적으로 결정하며 임의로 건너뛰지 않는다. 기존 여러 줄 답변의 표시·제출 불일치는 사용자 진행 요청에 따라 먼저 [복원 보완](../../Window/작업계획/13_기존답변복원보완.md)을 구현·검증하고 exe를 재생성했다.

실제 자료의 대량 재작성은 새 형식과 앱 지원을 확인한 뒤 진행한다. 기존 문항의 학습 대상이 달라지면 새 ID를 사용하고 과거 시험을 보존한다.

기존 Windows 계획의 1~5단계 완료 상태는 유지한다. 다음 기능 작업은 위 확장 순서로 진행하고, 기존 6단계 자료 교환·백업·복구는 확장된 자료와 평가 이력을 다루도록 후속 설계를 조정한다. [Windows 확장 계획](../../Window/작업계획/12_학습방식확장계획.md)

표에서 사용자 확정으로 표시한 항목만 결정된 요구다. 나머지 제안은 사용자 확정을 뜻하지 않는다. 신규 DB 2 소스는 혼합 시험·평가/기초 복습을 구현하고 가상 검증했으며 기존 배포 exe는 아직 JSON 1.0 단답형 경로를 유지한다.

남은 정책은 [상태와 재계산 계약 초안](../상세설계/학습규칙/02_3_평가상태와재계산.md)에 하나의 권장 조합과 영향을 구체화했다. 손상 원천은 영향 문항의 쓰기를 차단하는 안, 수동 편입은 별도 이벤트로 보존하는 안이다. 확장 1을 완료로 표시하지 않고, 정책에 의존하지 않는 자료/연결 검토부터 진행한다. 자료 형식 2.0·선행 연결 위치·자원 상한은 내부 파서 기준으로 구현했다. 평가/수동 복습 명령과 원자적 집계는 권장안 검증 구현으로 진행했다. DB 2 시험 저장소·화면도 연결했다. 정책 점검·실제 DB 전환·자료 보강·배포는 남아 있다.
