# 작업 완료와 문서 갱신

확정일: 2026-11-25. 기능 작업은 구현·검증과 관련 문서 갱신을 함께 완료한다. 별도 요청이 없어도 이후 작업에 적용한다.

| 바뀐 내용 | 갱신할 문서 |
| --- | --- |
| 공통 동작·원칙·데이터 규칙 | 해당 공통 설계·상세 설계·개발 원칙 |
| 플랫폼 기술·호출·화면·저장 동작 | 해당 플랫폼의 구현 설계·화면 흐름·저장 방식 |
| 구현 단계의 상태·다음 작업 | 플랫폼 구현 진행 계획과 공통 프로젝트 작업 현황 |
| 구현 내용·검증 결과·제한·실행 방법 | 플랫폼의 단계별 작업 결과 문서 |
| 문서 추가·이동 | 해당 폴더와 진입점 README의 경로 |

실제 구현 완료와 설계만 작성한 상태를 구분하고, 검사한 범위·결과와 미확인 항목을 기록한다. 문서 링크와 변경분을 확인한 뒤 작업 결과를 보고한다. 기능 완료를 근거 없이 표시하거나 실제 문항·정답·답변을 문서에 옮기지 않는다.

전체 설계와 현황은 요약을 유지하고 세부 구현·검증은 해당 주제와 작업 결과 문서로 연결한다. 문서 갱신이 commit·push를 자동 수행한다는 뜻은 아니며 Git 작업은 사용자의 별도 지시를 따른다.
