# 학습 문항 보충 정보

상태: 초기 설계 기준. 사용자 요구와 이번 작업의 구현 기준을 함께 반영했다.

설명과 예시 및 출처는 문항 본체와 분리해 선택적으로 연결한다. 보충 정보가 없어도 출제와 채점에 필요한 정보는 [학습 데이터](01_학습데이터.md)에 포함한다.

## 연결 구조 기준

| 필드 | 형식 | 역할 |
| --- | --- | --- |
| `schema_version` | 문자열 | 보충 정보 형식의 버전 |
| `dataset_id` | 문자열 | 연결할 데이터 묶음 식별자 |
| `items` | 배열 | 문항별 보충 정보 |
| `dataset_metadata` | 객체 | 선택 필드. 원자료의 언어와 작성 정보 등 |

## 문항별 필드 기준

| 필드 | 형식 | 역할 |
| --- | --- | --- |
| `id` | 문자열 | 연결할 문항의 식별자. 필수 |
| `explanation` | 문자열 | 개념과 정답의 해설. 선택 |
| `example` | 문자열 | 이해를 돕는 예시. 선택 |
| `caution` | 문자열 | 주의점과 흔한 오해. 선택 |
| `category` | 문자열 | 분류. 선택 |
| `tags` | 문자열 배열 | 검색과 필터용 태그. 선택 |
| `sources` | 문자열 배열 | 참고한 자료의 URL. 선택 |
| `source_refs` | 객체 배열 | 보관한 원문 항목의 묶음과 문항 식별자. 일반 문항은 선택, 변환 문항은 포함 |

대표 정답과 허용 표기는 채점에 필요한 정보이므로 보충 정보로 옮기지 않는다.

## 누락과 연결 오류 기준

보충 정보가 없는 문항은 보충 항목을 생략한다. 동일 묶음과 문항 식별자로 연결하고, 대응하는 문항이 없으면 미연결 항목으로 안내한다. 보충 정보만으로 새 시험 문항을 만들지 않는다. 연결 검증은 [기록 연결과 보존](03_2_기록연결과보존.md)을 따른다.

`source_refs`의 필드와 원문 및 결과 문항의 대응은 [원문 대응과 변환 결과](04_2_원문대응과변환결과.md)에서 정의한다. 자료 준비 과정에서는 보관한 실제 원문과 연결을 검증한다. 앱 가져오기에서는 원문 식별자 형식을 보존하며, 원문 파일을 배포하지 않았다는 이유로 출제나 채점을 막지 않는다.
