# 문항 평가 이력과 현재 평가

작성일: 2026-11-26. 수정일: 2026-11-27. 상태: DB 2 시험의 최초/현재 평가·사용자 정정·재계산·화면 연결 가상 검증 완료. 기존 DB 1의 활성 전환과 실제 자료/배포는 남아 있다.

테이블 책임은 [Windows 저장 구조 초안](../../../Window/구현설계/확장/01_저장구조.md), 원래 시도 순서·수동 편입과의 연결은 [재계산 계약 초안](../학습규칙/02_3_평가상태와재계산.md)에 정리했다. 두 문서는 미확정 정책에 조건부이며 현재 DB 명세를 대체하지 않는다.

## 보존할 정보의 구분

| 구분 | 보존할 내용 |
| --- | --- |
| 출제 기준 | 당시 문항 유형, 질문, 단답형 정답 표기 또는 서술형 참고 답안·핵심 내용, 평가 규칙 버전 |
| 제출 답변 | 최종 제출한 원문과 제출 시점. 평가 정정으로 수정하지 않음 |
| 최초 평가 | 자동 판정 또는 최초 사용자 평가의 구분·기준·결과 |
| 평가 이력 | 어떤 응답에 대한 변경인지, 이전·이후 평가, 평가 주체/방식, 변경 시점, 버전, 선택적 사유 |
| 현재 유효 평가 | 화면 점수·복습 집계에 적용하는 최신 평가와 이력 연결 |

평가 이력은 같은 시험·문항 위치와 사용자에 연결한다. 새 평가·정정은 이력을 추가하고 과거 이력을 덮어쓰지 않는다. 원본 문항과 답변을 바꾸거나 새 시험으로 복제해 평가 변경을 표현하지 않는다. 원래 자동 판정과 현재 유효 평가를 구분해 조회한다.

## 저장 일관성

- 진행 답변 revision과 평가 revision은 구분한다. 제출 후 답변 잠금은 유지한다.
- 사용자가 확인한 평가 버전과 현재 버전이 다르면 충돌을 안내하고 오래된 화면으로 덮어쓰지 않는다.
- 같은 평가 요청의 재시도가 이력·점수·학습 상태를 중복 반영하지 않도록 요청 식별과 멱등 처리를 정한다.
- 평가 이력 추가·현재 평가 변경·시험 요약과 문항 학습 상태의 재계산을 하나의 저장 단위로 처리한다. 중간 실패는 전체 롤백한다.
- 평가 시각을 바꾸어 시험의 학습 순서를 재배치하지 않는다. 원래 시도의 순서와 그 시도에 대한 최신 유효 평가를 사용한다.

예전 시험의 평가를 고치면 그 문항의 이후 시도도 다시 반영해 현재 상태를 계산한다. 화면에 남은 이전 결과의 점수와 평가를 갱신할 수 있도록 조회 버전과 새로고침 계약을 정의한다. 조회만으로 평가 이력을 추가하거나 연속 정답 수를 늘리지 않는다.

## 기존 자료와 기록

기존 응답의 원문·판정·완료 순번은 보존한다. 전환 전부터 존재한 자동 판정을 최초 평가로 어떻게 연결할지 마이그레이션에서 정의하며, 과거 단답형을 소급해 서술형으로 해석하지 않는다. 응답에서 단어나 핵심 내용을 임의로 추출해 평가 기준을 만들지 않는다.

새 이력도 사용자 기록이므로 DB·백업과 함께 Git·문서·검증 로그에서 제외한다. 교환·복구 설계는 원문 답변·최초 평가·정정 이력·최신 평가의 연결을 함께 보존해야 한다. [사용자 평가 규칙](../학습규칙/02_2_사용자평가와정정.md), [기록 보존](03_2_기록연결과보존.md)
