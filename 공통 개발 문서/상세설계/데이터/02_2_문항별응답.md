# 시험 문항별 응답 데이터

상태: 초기 설계 기준. 사용자 요구와 이번 작업의 구현 기준을 함께 반영했다.

시험에 출제한 문항 하나의 내용과 답변을 보존한다. 원본 자료가 수정되어도 진행 중인 시험과 과거 결과는 출제 당시의 내용으로 확인한다.

## 필드 기준

| 필드 | 형식 | 역할 |
| --- | --- | --- |
| `exam_id` | 문자열 | 소속 시험 식별자 |
| `position` | 정수 | 시험에서의 표시 위치. 0부터 시작 |
| `dataset_id` | 문자열 | 원본 데이터 묶음 식별자 |
| `item_id` | 문자열 | 원본 문항의 `id` |
| `question_snapshot` | 문자열 | 출제 당시 질문 |
| `answer_snapshot` | 문자열 | 출제 당시 대표 정답 |
| `accepted_answers_snapshot` | 문자열 배열 | 출제 당시 허용 표기. 없으면 빈 배열 |
| `response_text` | 문자열 | 입력 답변 원문. 입력 전에는 빈 문자열 |
| `judgement` | 문자열 | `ungraded`, `correct`, `incorrect` 중 하나 |
| `incorrect_reason` | 문자열 또는 null | 오답이면 `no_match` 또는 `unanswered`, 그 외에는 null |

## 연결과 보존 기준

시험 식별자와 표시 위치의 조합은 유일하다. 같은 시험에서 동일한 묶음과 문항 식별자의 조합을 중복 출제하지 않는다. 원본이 수정되거나 제거된 경우의 참조는 [기록 연결과 보존](03_2_기록연결과보존.md)을 따른다.

진행 중 답변은 자동 저장하고 수정할 수 있다. 최종 제출 후에는 제출한 답변을 기준으로 처리한다. 문항 원본과 허용 표기를 다시 읽어 기존 시험의 채점 기준을 바꾸지 않는다.

## 판정 기록 기준

최종 제출 전과 제출 후 완료 처리 전에는 모든 문항이 `ungraded`다. 완료된 시험은 모든 문항에 `correct` 또는 `incorrect`가 있어야 한다. 완료 처리 실패 시 판정 저장도 전체 롤백하므로 일부 문항만 채점된 상태를 확정하지 않는다.

정답과 허용 표기 중 하나에 완전히 일치하면 `correct`다. 제출된 미응답은 `incorrect`와 `unanswered`로 기록하고, 다른 불일치는 `incorrect`와 `no_match`로 기록한다. 입력 답변은 공백 등을 정리하지 않고 보존한다.

판정 기준은 [자동 채점 기준](../학습규칙/02_1_자동채점기준.md)을 따른다.
