# 시험 기록 데이터

상태: 초기 설계 기준. 사용자 요구와 이번 작업의 구현 기준을 함께 반영했다.

시험 한 회를 식별하고, 출제할 때 정한 설정과 진행 상태를 보존한다. 출제한 문항과 답변은 [문항별 응답](02_2_문항별응답.md)으로 연결한다.

## 필드 기준

| 필드 | 형식 | 역할 |
| --- | --- | --- |
| `exam_id` | 문자열 | 시험 한 회의 고유 식별자 |
| `learner_id` | 문자열 | 기록을 소유하는 사용자 식별자 |
| `status` | 문자열 | `in_progress`, `submitted`, `completed` 중 하나 |
| `revision` | 정수 | 진행 중 답변·위치의 편집 버전. 0부터 시작하고 변경마다 증가 |
| `dataset_ids` | 문자열 배열 | 선택한 데이터 묶음과 선택 순서 |
| `dataset_titles_snapshot` | 객체 | 선택한 묶음 ID별 출제 당시 자료명. 원본 제거 후에도 기록 목록에서 표시 |
| `question_count` | 정수 | 실제 출제한 문항 수 |
| `count_mode` | 문자열 | 전체 `all` 또는 개수 지정 `count` |
| `order_mode` | 문자열 | 무작위 `random` 또는 순서대로 `ordered` |
| `review_mode` | 문자열 | 일반 `general`, 오답 우선 `wrong_first`, 오답만 `wrong_only` |
| `current_position` | 정수 | 현재 문항 위치. 0부터 시작 |
| `grading_rule_version` | 문자열 | 시험에 적용한 문자열 비교 규칙의 버전 |
| `started_at` | 시각 문자열 | 시험을 시작한 시점 |
| `saved_at` | 시각 문자열 | 마지막 저장 성공 시점 |
| `submitted_at` | 시각 문자열 또는 null | 최종 제출 전에는 null |
| `completed_at` | 시각 문자열 또는 null | 채점과 결과 저장 완료 전에는 null |
| `completion_order` | 정수 또는 null | 사용자별 완료 반영 순번. 완료 전에는 null |

`dataset_titles_snapshot`은 선택한 `dataset_ids` 각각의 이름을 포함한다. 시각은 UTC로 저장해 화면에서 표시 시간대로 바꾼다. 새 ID의 형식과 식별 범위는 [식별과 관계](03_식별과관계.md)를 따른다.

## 상태와 연결 기준

`in_progress`는 답변 작성과 이어 풀기, `submitted`는 제출 답변에 대한 채점과 저장 처리, `completed`는 확정 결과 조회에 사용한다.

문항 수는 1 이상이고, 현재 위치와 문항별 응답의 위치는 0부터 `question_count - 1` 사이여야 한다. 문항별 응답은 위치가 중복되지 않게 연결한다. 시험 시작 시 전체 문항의 질문과 정답 및 허용 표기를 보존하고, 이어 풀기에서는 같은 시험과 순서를 사용한다.

`completed_at`과 `completion_order`는 처음 완료할 때 고정한다. 같은 사용자의 완료 순번은 유일하고 증가하며, 저장 재시도로 바꾸지 않는다. 학습 결과 반영에는 시각 대신 이 순번을 사용한다.

처리 실패 시 기존 상태와 마지막 저장 성공 기록을 보존한다. 저장 재시도로 새로운 시험을 생성하지 않는다. 편집 버전은 [자동 저장](../../../Window/저장방식/04_진행상태저장과복구.md), 완료 확정은 [완료 처리](../../../Window/저장방식/02_1_완료처리와중복방지.md)를 따른다.

동작 기준은 [진행 저장과 재개](../학습규칙/03_1_진행저장과재개.md)를 따른다.
