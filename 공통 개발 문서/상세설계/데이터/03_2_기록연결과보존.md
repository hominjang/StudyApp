# 시험 기록 연결 검증과 보존

상태: 초기 설계 기준. 사용자 요구와 이번 작업의 구현 기준을 함께 반영했다.

진행 중 시험과 과거 결과는 출제 당시 보존한 문항으로 확인한다. 현재 원본 자료와의 연결은 이후 출제와 문항별 학습 상태를 구분하는 데 사용한다.

## 연결 검증 기준

- 새 시험의 문항은 현재 선택한 자료 안에 있어야 하고, 문항별 응답의 `dataset_id`는 시험의 `dataset_ids`에 포함되어야 한다.
- 응답의 `exam_id`는 실제 시험 기록을 가리키고, 위치는 시험의 문항 수 범위 안에서 유일해야 한다.
- 보충 정보는 같은 묶음의 문항에만 연결한다. 대응 문항이 없는 항목은 미연결로 안내하고 정답이나 문항을 임의로 만들지 않는다.
- 문항 학습 상태는 같은 사용자의 완료된 시험과 해당 문항의 응답만 참조한다.
- `last_completed_exam_id`가 있으면 같은 사용자의 완료된 시험이며 해당 문항의 응답을 포함해야 한다.

같은 `exam_id`로 저장을 재시도하면 같은 시험의 처리 단계를 이어가고, 이미 완료된 시험의 결과는 유지한다. 별도 기록 가져오기에서 같은 시험 ID에 서로 다른 내용이 연결되면 충돌로 안내하며 기존 기록을 자동 덮어쓰지 않는다.

## 원본 변경 후 보존 기준

- 원본의 질문과 정답 또는 허용 표기를 수정해도 시험에 보존한 내용은 바꾸지 않는다.
- 원본 자료를 제거해도 진행 중 시험은 저장된 문항과 답변으로 이어 풀고, 완료된 시험은 저장된 내용으로 조회한다.
- 원본이 없는 응답의 묶음과 문항 ID는 출처 연결 정보로 보존한다. 원본이 없다는 이유로 응답과 시험을 함께 삭제하지 않는다.
- 새 묶음이나 새 문항 ID에는 기존 학습 상태를 자동으로 연결하지 않는다.

진행 중 상태는 [시험 기록](02_1_시험기록.md), 보존하는 문항 내용은 [문항별 응답](02_2_문항별응답.md), 현재 오답 대상은 [문항 학습 상태](02_3_문항학습상태.md)에서 정의한다.

초기 버전은 시험 기록 자체를 삭제하거나 확정 결과를 수정하는 기능을 제공하지 않는다. 시험과 응답의 연결 및 파생 상태 재계산은 [학습 기록 저장](../../../Window/저장방식/02_학습기록저장.md)을 따른다.
