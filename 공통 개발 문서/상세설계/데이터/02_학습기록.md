# 학습 기록 데이터 구성

상태: 초기 설계 기준. 사용자 요구와 이번 작업의 구현 기준을 함께 반영했다.

학습 원본과 사용자 기록을 분리한다. 시험마다 진행 상태와 응답을 보존하고, 완료된 결과에서 문항별 학습 상태를 계산한다.

| 구성 | 역할 | 세부 문서 |
| --- | --- | --- |
| 시험 기록 | 한 회의 출제 설정과 진행 및 제출 상태 | [시험 기록](02_1_시험기록.md) |
| 문항별 응답 | 출제 당시 문항과 입력 답변 및 판정 | [문항별 응답](02_2_문항별응답.md) |
| 문항 학습 상태 | 사용자별 오답 대상과 연속 정답 횟수 | [문항 학습 상태](02_3_문항학습상태.md) |
| 평가 이력과 현재 평가 | 최초 평가·정정 이력·현재 유효 평가의 연결. 확장 설계이며 미구현 | [평가 이력](02_4_평가이력.md) |

시험 하나에 출제한 수만큼 문항별 응답이 연결된다. 같은 문항을 다시 풀면 새로운 시험과 응답을 만들고, 해당 사용자의 문항 학습 상태에 완료 결과를 반영한다.

진행 중이거나 최종 제출 후 처리 중인 기록은 이어 풀기와 처리 재개에 사용한다. 다음 시험의 오답 대상 판단에는 완료된 결과만 사용한다.

사용자와 묶음 및 문항의 식별 범위는 [식별과 관계](03_식별과관계.md), 원본과 기록의 연결 검증은 [기록 연결과 보존](03_2_기록연결과보존.md)에서 정의한다. 저장소와 실제 저장 구조는 저장 상세 설계에서 정한다.
