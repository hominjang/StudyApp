# 사용자별 문항 학습 상태

상태: 초기 설계 기준. 사용자 요구와 이번 작업의 구현 기준을 함께 반영했다.

완료된 시험의 응답에서 현재 오답 대상과 연속 정답 횟수를 계산한다. 이 상태는 원본 기록에서 다시 계산할 수 있는 자료로 두고, 과거 응답을 덮어쓰지 않는다.

## 필드 기준

| 필드 | 형식 | 역할 |
| --- | --- | --- |
| `learner_id` | 문자열 | 사용자 식별자 |
| `dataset_id` | 문자열 | 데이터 묶음 식별자 |
| `item_id` | 문자열 | 문항 식별자 |
| `is_review_target` | 불리언 | 현재 오답 대상 여부 |
| `correct_streak` | 정수 | 오답 이후의 연속 정답 수. 0부터 3까지 |
| `last_result` | 문자열 또는 null | 가장 최근 완료 결과인 `correct` 또는 `incorrect`. 기록이 없으면 null |
| `last_completed_exam_id` | 문자열 또는 null | 가장 최근 반영한 시험 식별자 |

사용자와 묶음 및 문항 식별자의 조합으로 하나의 학습 상태를 구분한다. 완료된 결과가 없는 문항은 오답 대상이 아니며 연속 정답 수는 0이다. 원본 자료의 갱신과 새 ID가 기존 상태에 미치는 영향은 [변경과 재가져오기](03_1_변경과재가져오기.md)를 따른다.

## 갱신 기준

- 오답이면 오답 대상으로 편입하고 연속 정답 수를 0으로 초기화한다.
- 오답 대상일 때 정답이면 횟수를 1 늘리고, 3이 되면 오답 대상에서 제외한다.
- 오답 대상이 아닌 문항을 맞히면 현재 상태를 유지한다. 처음부터 정답인 문항은 0, 제외된 문항은 3으로 유지한다.
- 해당 문항이 출제되지 않은 시험과 진행 중인 시험은 횟수를 바꾸지 않는다.

## 기록 반영 기준

사용자의 완료된 시험을 `completion_order` 순으로 반영한다. 완료 시각은 화면 표시용이며 시스템 시계가 바뀌어도 학습 결과의 적용 순서를 바꾸지 않는다. 각 시험의 해당 문항 결과는 한 번만 반영한다.

`last_completed_exam_id`는 조회를 돕는 값이다. 상태는 완료된 원본 기록의 시험 식별자로 중복을 구분해 재계산한다. 시험 완료와 상태 갱신은 [같은 트랜잭션](../../../Window/저장방식/02_1_완료처리와중복방지.md)으로 확정한다.

학습 규칙은 [오답 대상 관리](../학습규칙/04_1_오답대상관리.md)를 따른다. 오답 대상을 조회할 때는 현재 출제 범위 안의 문항만 사용한다.
