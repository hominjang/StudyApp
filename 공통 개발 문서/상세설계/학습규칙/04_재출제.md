# 학습 기록을 반영한 재출제

상태: 초기 설계 기준. 사용자 요구와 이번 작업의 구현 기준을 함께 반영했다.

사용자가 선택한 자료와 문제 수 및 표시 방식에 이전 학습 기록을 결합해 다음 시험을 구성한다.

## 확정된 요구

- 시험 시작 시 일반·오답 우선·오답만 중 선택한다.
- 틀린 문항은 이후 3회 연속 정답이면 오답 대상에서 제외하고, 중간에 틀리면 연속 횟수를 초기화한다.
- 한 번 정답을 맞혔다는 이유만으로 오답 대상에서 바로 제외하지 않는다.

연속 정답 횟수와 오답 대상 상태는 [오답 대상 관리](04_1_오답대상관리.md)에서 정의한다.

## 모드별 문항 구성 기준

| 모드 | 구성 |
| --- | --- |
| 일반 | 오답 대상 여부로 우선순위를 주지 않고 선택한 범위에서 출제 |
| 오답 우선 | 오답 대상에서 먼저 필요한 수를 선택하고, 부족하면 나머지 문항에서 보충 |
| 오답만 | 오답 대상인 문항에서만 출제 |

먼저 모드에 따라 문항을 선택한 뒤, 무작위 또는 순서대로 설정에 따라 표시 순서를 정한다. 순서대로는 선택한 데이터 묶음의 순서와 각 묶음의 문항 순서를 따른다.

오답 우선에서 오답 대상과 나머지 후보를 고를 때도 선택한 순서 방식을 적용한다. 무작위면 각 그룹에서 중복 없이 추출하고, 순서대로면 각 그룹의 자료 순서 앞에서부터 고른다. 이후 선택된 문항 전체의 표시 순서를 적용한다. 따라서 오답 우선은 문항을 고르는 우선순위이며 화면에서 항상 오답부터 표시한다는 뜻은 아니다.

전체 출제는 해당 모드의 후보 전체를 뜻한다. 일반과 오답 우선에서는 선택 범위의 전체 문항, 오답만에서는 선택 범위의 오답 대상 전체를 포함한다.

## 범위와 기록 기준

- 사용자가 선택한 데이터 묶음 안의 문항만 출제한다.
- 현재 사용자의 완료된 시험 기록만 오답 대상 판단에 반영한다. 진행 중이거나 처리 중인 시험은 제외한다.
- 이어 풀기는 기존 시험을 복원하는 작업이다. 재출제 규칙을 다시 적용하지 않는다.
- 오답 판정과 오답 대상의 관계는 문항 식별자로 연결한다. 질문 문장으로 기록을 연결하지 않는다.

## 후보 부족 기준

오답 우선에서 오답 대상이 없으면 일반 후보에서 구성한다. 오답만에서 대상이 없으면 안내하고 다른 모드나 자료 범위를 선택하도록 한다.

지정한 문제 수가 해당 모드의 후보보다 많으면 가능한 개수를 안내하고 다시 선택하게 한다. 오답만 모드에 다른 문항을 임의로 섞지 않는다.

## 연결할 설계

공통 출제 설정은 [출제](01_출제.md), 완료 기록의 기준은 [결과 기록](03_결과기록.md)을 따른다.
