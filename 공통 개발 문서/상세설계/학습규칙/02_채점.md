# 시험 답변 채점 설계

상태: 아래 단답형 자동 채점은 DB 1 호환 기준이다. 신규 DB 2는 서술형 미평가·사용자 평가·부분정답·정정을 구현하고 가상 검증했다. 확장 동작은 사용자 평가 상세 문서를 따르며 기존 사용자 DB 전환과 배포는 남아 있다.

단답형은 대표 정답이나 등록된 허용 표기 중 하나와 완전히 같은지 비교해 자동 채점한다. 서술형은 제출 답변을 저장한 뒤 사용자가 참고 답안과 핵심 내용으로 평가하는 방식으로 확장한다. 평가는 학습 기록과 다음 출제에 연결한다.

## 확정된 요구

- 시험에서 틀린 문항을 확인할 수 있어야 한다.
- 문항별 평가 결과를 저장하고 다음 시험에 활용해야 한다.
- 단답형은 단답이나 짧은 문장으로 답하게 작성하고, 대표 정답이나 등록된 허용 표기 중 하나와 완전히 같아야 자동 정답으로 판정한다.
- 서술형·사용자 평가·부분정답·나중 평가 정정 지원을 추가한다. 세부 집계는 구현 전 확정한다.
- 시험을 최종 제출한 뒤 평가 기준을 공개한다. 단답형은 자동 판정 결과를 함께 공개하고, 서술형의 사용자 평가는 나중에 저장할 수 있게 한다.
- 제출 전에 미응답 문항을 안내하고, 사용자가 그대로 제출하면 해당 문항은 오답으로 기록한다.

## 채점 기준 연결

단답형 문자열 비교와 공통 미응답 목록은 [자동 채점 기준](02_1_자동채점기준.md)에서 정의한다. 긴 설명의 의미를 추론하거나 키워드를 추출해 자동 평가하지 않는다. 서술형의 미평가·사용자 평가·정정은 [사용자 평가 규칙](02_2_사용자평가와정정.md)을 따른다.

## 평가 처리 기준

아래 순서는 현재 구현된 단답형 기준이다. 서술형이 섞인 시험의 제출·평가 완료 분리는 확장 설계에서 정의한다.

1. 시험 시작 시 문항별 채점 기준의 사용 가능 여부를 확인한다.
2. 시험 작성 화면에서는 최종 제출 전 정답과 문항별 판정 결과를 공개하지 않는다. 별도 자료 학습은 현재 질문·답을 함께 읽는 기능이며 채점·시험 기록을 만들지 않는다.
3. 미응답이 있으면 해당 문항을 안내한다. 사용자는 답변 작성으로 돌아가거나 그대로 최종 제출한다.
4. 최종 제출된 답변을 자동 채점하고, 미응답 문항은 오답으로 처리한다.
5. 제출 답변과 판정 결과를 결과 기록 처리에 전달한다.
6. 채점과 결과 기록이 완료되면 시험 결과에서 정답과 문항별 판정을 한 번에 확인한다.

## 상태와 예외 기준

- 판정이 끝나지 않았거나 채점 처리에 실패한 문항은 미채점으로 구분하고 오답으로 간주하지 않는다.
- 채점 기준 누락과 형식 오류는 시험 시작 전에 안내하고, 해결 후 출제한다.
- 처리 실패 시 시험 결과를 완료로 확정하지 않고 재처리가 필요함을 안내한다.

현재 단답형 자동 채점은 불일치를 오답으로 판정하며 부분 점수를 부여하지 않는다. 현재 앱은 확정 결과의 조회만 제공한다. 확장 후에는 제출 원문·최초 평가를 보존하고 사용자 평가와 정정 이력을 추가한다. 재학습을 위한 새 응시와 기존 응답의 평가 정정은 구분한다.

## 연결할 설계

출제된 문항과 순서는 [출제](01_출제.md)를 따른다. 기록 시점과 확정 기준은 [결과 기록](03_결과기록.md)에서 정의한다.
