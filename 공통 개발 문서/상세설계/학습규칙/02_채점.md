# 시험 답변 채점 설계

상태: 초기 설계 기준. 사용자 요구와 이번 작업의 구현 기준을 함께 반영했다.

단답이나 3~4개 단어로 된 짧은 문장을 정답으로 사용한다. 제출 답변이 대표 정답이나 등록된 허용 표기 중 하나와 완전히 같은지 비교해 자동 채점한다. 판정 결과는 학습 기록과 다음 시험의 출제에 연결한다.

## 확정된 요구

- 시험에서 틀린 문항을 확인할 수 있어야 한다.
- 문항별 평가 결과를 저장하고 다음 시험에 활용해야 한다.
- 모든 문항은 단답이나 짧은 문장으로 답하게 작성하고, 대표 정답이나 등록된 허용 표기 중 하나와 완전히 같아야 정답으로 판정한다.
- 시험을 최종 제출한 뒤 정답과 판정 결과를 한 번에 공개한다.
- 제출 전에 미응답 문항을 안내하고, 사용자가 그대로 제출하면 해당 문항은 오답으로 기록한다.

## 채점 기준 연결

문자열 비교와 미응답 처리는 [자동 채점 기준](02_1_자동채점기준.md)에서 정의한다. 단답형 정답과 비교하며, 긴 설명의 의미를 추론하거나 키워드를 추출해 평가하지 않는다.

## 평가 처리 기준

1. 시험 시작 시 문항별 채점 기준의 사용 가능 여부를 확인한다.
2. 최종 제출 전에는 정답과 문항별 판정 결과를 공개하지 않는다.
3. 미응답이 있으면 해당 문항을 안내한다. 사용자는 답변 작성으로 돌아가거나 그대로 최종 제출한다.
4. 최종 제출된 답변을 자동 채점하고, 미응답 문항은 오답으로 처리한다.
5. 제출 답변과 판정 결과를 결과 기록 처리에 전달한다.
6. 채점과 결과 기록이 완료되면 시험 결과에서 정답과 문항별 판정을 한 번에 확인한다.

## 상태와 예외 기준

- 판정이 끝나지 않았거나 채점 처리에 실패한 문항은 미채점으로 구분하고 오답으로 간주하지 않는다.
- 채점 기준 누락과 형식 오류는 시험 시작 전에 안내하고, 해결 후 출제한다.
- 처리 실패 시 시험 결과를 완료로 확정하지 않고 재처리가 필요함을 안내한다.

등록된 어느 정답 표기와도 같지 않으면 오답으로 판정하며 부분 점수를 부여하지 않는다. 초기 버전에서 확정된 결과는 조회만 제공한다. 새 평가는 새 시험으로 남긴다.

## 연결할 설계

출제된 문항과 순서는 [출제](01_출제.md)를 따른다. 기록 시점과 확정 기준은 [결과 기록](03_결과기록.md)에서 정의한다.
