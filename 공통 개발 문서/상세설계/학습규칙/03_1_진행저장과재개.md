# 시험 진행 저장과 재개

상태: 초기 설계 기준. 사용자 요구와 이번 작업의 구현 기준을 함께 반영했다.

시험을 중단해도 마지막으로 저장한 문항과 답변 상태에서 이어 풀 수 있게 한다. 최종 결과 기록은 [결과 기록](03_결과기록.md)을 따르고, 저장할 데이터는 [시험 기록](../데이터/02_1_시험기록.md)과 [문항별 응답](../데이터/02_2_문항별응답.md)에서 정의한다.

## 자동 저장 기준

- 시험을 시작할 때 시험 식별자와 선택한 자료의 ID와 이름 및 출제 설정, 문항과 표시 순서, 당시의 질문과 대표 정답 및 허용 표기와 비교 기준을 저장한다.
- 답변과 위치 변경 후 500ms 대기와 최대 2초 간격의 저장 요청을 적용한다. 편집 버전으로 오래된 요청을 막는 [자동 저장 기준](../../../Window/저장방식/04_진행상태저장과복구.md)을 따른다.
- 문항 이동과 정상적인 시험 중단 및 최종 제출 시에는 최신 상태를 저장한다.
- 마지막 저장 성공 시점과 저장 중 또는 실패 여부를 사용자가 구분할 수 있게 한다.

## 이어 풀기 기준

1. 중단한 시험을 선택하고 마지막으로 저장에 성공한 상태를 불러온다.
2. 기존 시험 식별자와 문항 및 순서, 입력한 답변, 현재 문항 위치를 복원한다.
3. 기존 시험의 나머지 답변을 작성한다. 문제를 새로 뽑거나 시험 기록을 새로 생성하지 않는다.

원본 자료가 바뀌어도 해당 시험을 만들 때 저장한 내용과 비교 기준을 사용한다. 이어 풀기에서도 최종 제출 전까지 정답과 판정 결과를 공개하지 않는다.

## 처리 상태 기준

| 상태 | 처리 |
| --- | --- |
| 진행 중 | 답변 수정과 자동 저장 및 중단 후 이어 풀기 허용 |
| 최종 제출 후 처리 중 | 제출 답변을 보존하고 채점 및 결과 저장을 처리한다. 중단되면 같은 시험의 처리를 재개한다. |
| 완료 | 확정 결과 조회와 다음 시험 출제에 활용 |

최종 제출 후 처리 중에는 답변을 잠그고, 처리 재시도가 새 응시나 중복 결과를 만들지 않게 한다.

## 저장 실패 기준

저장 실패 시 입력한 내용을 유지하고 실패를 안내하며 재시도한다. 저장에 성공하지 않은 상태를 저장 완료로 표시하지 않는다. 중단 후 복원 기준은 마지막 저장 성공 상태다.

진행 중이거나 처리 중인 시험은 정답·오답 학습 통계와 재출제 판단에 반영하지 않는다. 완료된 시험만 반영한다.
