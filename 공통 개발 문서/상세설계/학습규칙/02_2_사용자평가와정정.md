# 사용자 평가·부분정답·평가 정정

작성일: 2026-11-26. 상태: 서술형 참고 답안의 4단어 제한 제외·초기 평가의 개수 표시는 사용자 확정. 신규 DB 2의 서술형·평가 정정 화면을 구현·가상 검증했다. 실제 자료 보강과 기존 DB 전환/배포는 남아 있다. 복습 집계 등 미확정 항목은 [확장 계획](../../작업계획/05_학습방식확장계획.md)에서 구분한다.

이 문서의 남은 제안을 구현 계약으로 연결한 [상태와 재계산 초안](02_3_평가상태와재계산.md)을 작성했다. 미응답 정정·평가 취소·수동 해제 등 추가 경계도 권장안으로만 두었으며 사용자 확정으로 간주하지 않는다.

## 평가 흐름

DB 2의 가상 완료 기록에서 최초 평가·정정·부분정답·원래 순서의 재계산을 수행하는 백엔드는 구현했다. 신규 DB 2의 사용자 평가 UI까지 연결했다. 기존 DB 1 활성 전환·실제 자료/배포는 남아 있다. 미확정 부분은 권장안 검증 구현으로 두며 [명령 결과](../../../Window/작업계획/16_손상기록과평가명령.md)에 실행 범위를 구분했다.

1. 문항 유형에 맞게 답변을 입력하고 진행 중에는 기존대로 자동 저장한다.
2. 전체 시험을 최종 제출한다. 미응답을 안내하고 제출 후에는 답변 원문을 잠근다.
3. 단답형은 기존 자동 채점을 수행한다. 서술형은 미평가로 보관하고 최종 제출 후에만 참고 답안·핵심 내용을 공개한다.
4. 사용자가 자신의 답변과 기준을 비교해 정답·부분정답·오답을 선택하고 저장한다. 평가는 나중에 이어서 할 수 있다.
5. 결과 조회·회고에서 평가를 정정하면 이력을 추가하고 현재 유효 평가와 학습 집계를 갱신한다.

서술형을 의미나 키워드로 자동 채점하는 기능은 이번 계획에 넣지 않는다. 기준 없이 맞다고 느끼는지 묻는 대신 참고 답안과 확인할 핵심 내용을 함께 제공한다. 서술형 미응답도 기존처럼 안내 후 오답을 기본값으로 적용하는 방향이며, 그 판정의 정정 허용 범위는 구현 전에 확정한다.

## 평가 구분

| 구분 | 의미 |
| --- | --- |
| 미평가 | 답변은 제출했지만 사용자가 아직 평가하지 않음. 시스템 처리 실패와 별도 |
| 정답 | 요구한 핵심 내용을 충족했다고 사용자가 인정 |
| 부분정답 | 일부 내용은 맞지만 핵심 내용의 누락이나 오류가 있음 |
| 오답 | 핵심 내용을 충족하지 못함. 제출한 미응답의 기본 판정 포함 |

2026-11-26 사용자 확정: 초기 서술형·혼합 시험은 정답·부분정답·오답·미평가 개수로 표시한다. 숫자 배점·부분정답 점수 환산·혼합 합계는 이번 초기 범위에 넣지 않는다. 미평가를 0점이나 오답으로 숨겨 집계하지 않고 평가된 수·미평가 수와 평가 진행 상태를 구분한다. 제출된 문항은 네 구분 중 하나에 포함되어야 한다.

현재 단답형 앱의 정답 비율 표시를 새 유형의 혼합 점수로 간주하지 않는다. 숫자 점수의 도입과 환산은 추후 별도 확장 사항이며, 현재 앱의 화면이나 채점 코드는 이번 정책 문서 갱신으로 바뀌지 않는다.

## 정정의 범위

제출한 답변과 출제 당시 기준은 보존하고 평가만 바꾼다. 기록 화면은 원래 평가와 최신 유효 평가 및 정정 여부를 구분한다. 숫자 점수와 오답 필터는 정책 확정 후 최신 유효 평가를 사용한다.

단답형 자동 오답도 사용자가 이번 응답에 한해 정정할 수 있게 하는 것은 제안 범위다. **이번 응답 인정과 자료의 허용 표기 추가는 별개다.** 평가 정정만으로 대표 정답·accepted_answers나 다른 응답의 판정을 변경하지 않는다. 자료 편집은 별도 명시적 동작과 의미 검토를 거친다.

## 복습 집계 제안

기존 오답 이후 3회 연속 정답 규칙은 유지한다. 아래 연결은 구현 전 확정할 제안이다.

| 평가 | 복습 상태 제안 |
| --- | --- |
| 정답 | 기존 정답과 동일하게 반영 |
| 부분정답 | 복습 대상으로 편입/유지하고 연속 정답 0으로 처리 |
| 오답 | 기존처럼 대상 편입·연속 횟수 0 |
| 미평가 | 집계에서 제외하며 정답 횟수를 늘리거나 초기화하지 않음 |

늦게 평가하거나 과거 평가를 고칠 때는 수정 시각이 아니라 원래 시험 시도의 순서에서 해당 문항의 최신 평가를 반영한다. 예전 오답을 정답으로 고치면 이후 연속 횟수와 현재 오답 대상도 재계산해야 한다. 미평가를 나중에 평가해 이미 표시한 복습 상태가 달라지는 경우도 포함한다.

## 상태와 실패 처리

답변 작성·최종 제출 상태, 자동 처리의 성공/실패, 사용자 평가 진행 상태를 구분한다. 사용자가 아직 평가하지 않았다는 이유로 계속 채점 오류 화면에 가두거나 다른 시험을 막지 않는다. 제출 완료와 평가 완료의 구분 및 완료 순번 부여 시점은 확장 1에서 결정한다. 특히 미평가 서술형이 섞인 시험의 단답형 결과가 언제 오답 대상에 반영되는지 함께 결정한다. 상태 이름·명령·DB 표현은 확장 2에서 구체화한다.

검토자 제안은 평가 진행 상태를 시험 상태와 별도로 관리하고, 제출 처리 확정 때 순번을 부여해 늦은 평가를 원래 위치에 반영하는 방식이다. 사용자 확정 사항은 아니다.

평가 저장 실패 시 이전 유효 평가와 집계를 유지하고 재시도를 안내한다. 재시도·동시 수정·이력 저장과 집계 변경의 일관성은 [평가 이력](../데이터/02_4_평가이력.md)을 따른다. 저장되지 않은 평가를 반영 완료로 표시하지 않는다.
