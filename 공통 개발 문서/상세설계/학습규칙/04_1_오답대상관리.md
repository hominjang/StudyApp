# 재학습을 위한 오답 대상 관리

상태: 단답형 정답·오답 집계는 현재 구현 기준. 기초 문항의 수동 오답노트 편입은 확장 방향 확정·미구현이다. 부분정답·미평가의 반영은 [사용자 평가](02_2_사용자평가와정정.md)의 제안이며 구현 전 확정한다.

개별 시험의 정답·오답 판정과 다음 시험을 위한 오답 대상 상태를 구분한다. 이번 시험에서 맞힌 문항도 3회 연속 정답 조건을 채우기 전에는 오답 대상에 남는다.

## 확정된 요구

- 틀린 문항을 오답 대상으로 관리한다.
- 오답 이후 해당 문항을 3회 연속 맞혀야 오답 대상에서 제외한다.
- 중간에 틀리면 연속 정답 횟수를 0으로 초기화한다.

## 연속 정답 집계

오답이 발생한 시점부터 이후의 정답을 집계한다. 해당 문항이 출제되지 않은 시험은 횟수에 영향을 주지 않는다. 오답 대상일 때 정답이면 횟수를 1씩 늘리고, 오답이면 0으로 되돌린다.

## 상태 처리 기준

1. 완료된 시험에서 오답이 발생하면 해당 문항을 오답 대상으로 편입한다.
2. 이후 완료된 시험에서 해당 문항의 정답은 연속 횟수를 늘리고, 오답은 횟수를 초기화한다.
3. 3회 연속 정답이면 오답 대상에서 제외한다. 과거 응시 기록은 유지한다.
4. 제외된 문항을 나중에 다시 틀리면 오답 대상으로 편입하고 새로운 정답 횟수 집계를 시작한다.

안내 후 제출한 미응답도 오답이므로 같은 규칙을 적용한다. 진행 중이거나 처리 실패한 시험은 집계하지 않으며, 같은 시험의 저장 및 채점 재시도가 정답 횟수를 늘리지 않게 한다.

## 검토 예시

- `오답 → 정답 → 정답`: 연속 2회로 오답 대상 유지.
- `오답 → 정답 → 오답 → 정답 → 정답`: 중간 오답 이후 연속 2회로 유지.
- `오답 → 정답 → 정답 → 정답`: 연속 3회로 오답 대상에서 제외.

여러 시험의 결과 반영 순서와 상태 필드는 [문항 학습 상태](../데이터/02_3_문항학습상태.md), 식별 범위는 [식별과 관계](../데이터/03_식별과관계.md)에서 검토한다. 출제 시 활용은 [재출제](04_재출제.md)를 따른다.

평가 정정 확장에서는 원래 시도의 순서와 현재 유효 평가로 이후 기록까지 다시 반영한다. 평가 수정 시각을 새 응시 시점으로 세거나 정정 횟수만큼 정답 횟수를 늘리지 않는다. 최초 판정과 정정 이력은 보존한다.

## 수동 오답노트 편입 확장

DB 2 서비스에서 수동 편입·중복 요청·해제/재편입·과거 평가 정정 후 보존을 가상 검증했다. 실제 응시나 오답 판정을 만들지 않고 별도 학습 이벤트로 저장한다. 아래 세부 정책은 권장안 구현이며 현행 앱/실제 사용자 DB에는 아직 활성 적용하지 않았다. [구현 결과](../../../Window/작업계획/16_손상기록과평가명령.md)

2026-11-26 사용자 방향: 결과·회고에서 모르는 기초 부분에 연결된 문항을 오답노트에 수동 추가하고 기존 오답 우선·오답만으로 복습한다. 별도 기초 학습 모드나 전용 시험 생성 로직은 추가하지 않는다.

여기서 오답노트에 추가한다는 것은 복습 대상으로 지정한다는 뜻이다. 상위 문항의 판정·점수를 고치거나, 기초 문항을 실제로 틀린 것처럼 응시·답변·오답 판정을 만들지 않는다. 기초 문항의 최초 오답 횟수도 허위로 늘리지 않는다.

수동 지정은 사용자와 묶음·문항 ID에 연결해 보존한다. 집계 재계산이 수동 지정을 지워버리지 않도록 완료된 응시 결과와 구분해 설계한다. 같은 대상을 반복 추가해 중복 기록이나 연속 횟수 변경을 만들지 않는다. 추가 사실과 원래 평가의 정정도 구분한다.

수동 추가 뒤 해제·재등록과 연속 정답 집계의 세부 기준은 확장 1에서 검토한다. 기존 3회 연속 정답 규칙을 재사용하는 방향은 제안이며, 수동 추가 시 기존 연속 횟수를 어떻게 다룰지까지 함께 정한다. 저장 필드·동작 순서·완료/정정과의 충돌 처리는 확장 2에서 구체화한다.
