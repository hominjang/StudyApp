# 시험 출제 설계

상태: 초기 설계 기준. 사용자 요구와 이번 작업의 구현 기준을 함께 반영했다.

사용자가 선택한 학습 자료에서 한 회의 시험에 사용할 문항과 표시 순서를 정한다. 이 문서는 시험 대상과 문제 선택을 다룬다.

## 확정된 요구

- 사용자가 선택한 질문–답 자료에서 출제한다.
- 모든 시험 문항은 단답이나 3~4개 단어로 된 짧은 문장으로 답할 수 있게 준비한다.
- 보충 정보가 없어도 문항을 사용할 수 있다.
- 이전 학습 기록이 있으면 다음 시험의 출제에 반영한다.

## 사용자가 정하는 출제 설정

사용자는 시험을 시작할 때 다음 항목을 선택한다.

| 항목 | 설정 |
| --- | --- |
| 자료 범위 | 데이터 묶음을 하나 또는 여러 개 선택 |
| 문제 수 | 사용자가 개수를 지정하거나 전체 출제 선택 |
| 표시 순서 | 무작위 또는 데이터 순서대로 선택 |
| 기록 반영 모드 | 일반·오답 우선·오답만 중 선택 |

## 문항 선택과 순서 기준

- 기록 없는 시험에서 무작위를 선택하면 전체 후보 중 필요한 수를 중복 없이 뽑고 표시 순서도 섞는다.
- 기록 없는 시험에서 순서대로를 선택하면 데이터 순서의 앞에서부터 필요한 수를 뽑아 표시한다. 여러 묶음을 선택했다면 사용자가 선택한 묶음의 순서대로 연결하고, 묶음 안에서는 문항 배열의 순서를 따른다.
- 전체 출제는 기록 반영 모드가 정한 후보 전체를 포함하며, 표시 순서에는 선택한 방식을 적용한다.
- 학습 기록이 있는 시험의 문항 선택과 모드별 후보 및 전체 출제의 범위는 [재출제](04_재출제.md)를 따른다.

## 출제 처리 기준

1. 사용자가 선택한 데이터 묶음과 출제 설정을 확인한다.
2. 자료와 학습 기록 및 기록 반영 모드로 출제 후보와 문항 선택 우선순위를 결정한다.
3. 해당 후보 범위에서 전체 또는 지정한 수만큼 문항을 선택한다. 후보보다 많은 수를 지정하면 설정 수정을 안내한다.
4. 시험에 포함된 문항과 표시 순서를 정하고 시험을 시작한다.

## 경계 조건 기준

- 한 시험에서는 동일한 문항을 중복 출제하지 않는다. 서로 다른 묶음의 문항을 구분하는 기준은 데이터 상세 설계에서 정의한다.
- 출제 가능한 문항이 없으면 시험을 시작하지 않고 자료 확인을 안내한다.
- 질문이나 답이 비어 있거나 식별자가 중복된 자료는 오류를 안내하고, 해결 후 출제한다.
- 설명형 참고 자료는 단답형 문항으로 재작성한 뒤 사용한다. 출제 중 긴 모범 답변에서 정답을 임의로 추출하지 않는다.
- 문제 수를 지정하는 경우 1개 이상이어야 하며, 출제 가능한 문항보다 많으면 범위 안의 개수로 다시 선택하도록 안내한다.
- 시험 시작 후에는 선택한 문항과 표시 순서를 유지한다. 새로운 출제 조건은 다음 시험에 적용한다.

## 검토 예시

기록 없는 50문항 자료에서 10문항을 지정하면, 무작위 방식에서는 서로 다른 문항 10개를 뽑고 순서대로 방식에서는 앞의 10문항을 출제한다. 전체 출제를 선택하면 두 방식 모두 50문항을 포함한다.

## 연결할 설계
