# 시험 결과 기록 설계

상태: 초기 설계 기준. 사용자 요구와 이번 작업의 구현 기준을 함께 반영했다.

시험 진행 상태와 답변을 저장해 이어 풀기를 지원한다. 최종 제출한 답변과 문항별 판정은 학습 기록으로 보존하고 다음 출제에 활용한다.

## 확정된 요구

- 제출 답변과 문항별 정답·오답 결과를 저장한다.
- 이전 학습 기록을 다음 시험의 출제에 반영한다.
- 미응답을 안내한 뒤 사용자가 그대로 제출한 문항은 오답으로 기록한다.
- 시험 진행 중에도 자동 저장한다.
- 중단한 시험은 저장된 상태에서 이어 풀 수 있게 한다.

## 기록할 내용 기준

| 구분 | 보존할 내용 |
| --- | --- |
| 시험 | 시험 식별자, 응시 사용자, 선택한 자료의 ID와 당시 이름 및 출제 설정, 문항과 표시 순서, 제출 시점 |
| 진행 상태 | 입력 중인 답변, 현재 문항 위치, 마지막 저장 시점, 최종 제출 여부 |
| 문항별 답변 | 출제 당시 질문과 대표 정답 및 허용 표기, 제출한 답변 원문, 연결된 문항 식별자 |
| 판정 | 적용한 채점 기준과 문항별 판정, 시험 처리 상태 |

시험 당시의 내용과 판정 기준을 보존해 이후 원본 자료가 수정되어도 같은 시험을 이어 풀고 과거 결과를 확인할 수 있게 한다. 진행 중 저장과 복원은 [진행 저장과 재개](03_1_진행저장과재개.md), 필드와 관계는 [학습 기록 데이터](../데이터/02_학습기록.md)에서 다룬다.

## 기록 시점과 확정 기준

1. 최종 제출 시 진행 중 저장하던 같은 시험 기록에 제출 답변을 확정하고 자동 채점 결과를 저장한다.
2. 판정과 시험 완료 및 해당 문항의 학습 상태를 한 트랜잭션으로 확정하고 완료 순번을 부여한다.
3. 완료된 시험 기록을 결과 화면과 다음 출제에서 참조한다.

같은 문항을 다시 푼 시험은 새로운 시험 기록으로 남긴다. 저장 재시도는 같은 시험을 중복 생성하지 않도록 처리한다.

## 예외와 남은 검토

채점이나 저장이 실패한 시험은 완료된 기록과 구분하고 다음 출제의 집계에 포함하지 않는다. 제출된 미응답은 오답으로 기록하고 미응답 사유도 보존한다. 완료 처리 중 실패하면 판정·완료·학습 상태를 함께 되돌린다.

기록 수정·삭제 기능의 제공 범위와 실제 저장 기술은 플랫폼 문서에서 정한다. Window의 초기 버전은 확정 결과를 조회만 제공하고, SQLite를 사용하는 [학습 기록 저장](../../../Window/저장방식/02_학습기록저장.md)과 [완료 처리](../../../Window/저장방식/02_1_완료처리와중복방지.md)를 따른다.

완료 기록을 다음 출제에 반영하는 기준은 [재출제](04_재출제.md)에서 정의한다.
