# StudyApp

선택한 질문–답 자료로 시험을 제공하고, 학습 기록을 다음 출제에 반영하는 학습 앱이다.

| 찾을 내용 | 경로 |
| --- | --- |
| 현재 구현 범위·검증 결과·다음 작업 | [프로젝트 작업 현황](<공통 개발 문서/작업계획/04_프로젝트작업현황.md>) |
| Windows 앱을 직접 실행해 확인할 항목 | [사용자 확인 체크리스트](Window/작업계획/검증/사용자확인체크리스트.md) |
| Android 구현 계획과 설계 | [Android](Android/README.md) |
| Windows 구현 계획과 설계 | [Window](Window/README.md) |
| 공통 목적·원칙·데이터와 학습 규칙 | [공통 개발 문서](<공통 개발 문서/README.md>) |
| 실제 자료를 Git에서 제외하는 기준과 로컬 준비 | [데이터와 Git 관리 원칙](<공통 개발 문서/개발원칙/01_실제데이터와Git관리.md>) |
| 매 작업의 문서 갱신과 완료 기준 | [작업 완료와 문서 갱신](<공통 개발 문서/개발원칙/02_작업완료와문서갱신.md>) |

실제 학습 자료와 원문·사용자 기록은 로컬 `data/` 등에 별도 보관하고 Git에 올리지 않는다. 새로 clone한 저장소에는 실제 자료가 없으며 필요한 자료는 위 원칙에 따라 로컬에서 준비한다.
