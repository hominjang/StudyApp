# 시험 결과 확인과 재학습 화면

상태: 완료·과거 결과 조회, 현재 오답 상태 표시와 같은 설정·오답 복습·기록 목록 진입 구현. [수행 결과](../작업계획/10_기록조회와오답재학습.md)

완료된 시험의 요약과 문항별 결과를 표시한다. 과거 시험도 같은 화면에서 조회하며 응시 당시의 질문과 정답 및 제출 답변을 사용한다.

## 결과 표시

| 영역 | 내용 |
| --- | --- |
| 시험 요약 | 자료명과 완료 시각, 전체·정답·오답 수와 정답 비율 |
| 결과 필터 | 전체·오답·미응답 중 선택. 미응답은 오답의 일부임을 표시 |
| 문항별 결과 | 응시 당시 질문, 내 답변, 대표 정답, 당시 허용 표기, 정답·오답과 미응답 사유 |
| 보충 정보 | 연결 가능한 해설과 출처. 없으면 설명 없이 결과 확인 가능 |
| 현재 학습 상태 | 현재 오답 대상 여부와 필요한 경우 연속 정답 횟수 |

내 답변과 정답 표기는 공백 차이도 식별할 수 있게 표시한다. 공백 표시 전환 등 화면 표현을 제공해도 보존한 문자열을 바꾸지 않는다.

정답 비율은 완료 시험의 정답 수를 전체 문항 수로 나눈 값이다. 미응답을 전체 수에서 빼거나 오답과 별도로 더해 집계하지 않는다.

## 판정과 현재 상태 구분

이번 시험의 판정은 보존한 결과이고, 현재 학습 상태는 이후 완료된 시험까지 반영한 값임을 표시한다. 이번에 맞혀도 3회 연속 정답을 채우기 전에는 오답 대상에 남을 수 있다.

오답 대상이면 복습 중과 연속 정답 수를, 대상이 아니면 대상 아님을 표시한다. 이 시험으로 조건을 채웠다고 확인되는 경우에만 대상 해제로 표현한다. 원본이 없어도 저장한 문항과 판정은 확인할 수 있다. 해설은 현재 연결 가능한 보충 정보를 사용한다.

## 다음 동작

- **새 시험 설정:** 기존 자료 범위와 설정을 채운 [자료 선택](01_데이터선택.md)으로 이동한다. 시작 전 변경 가능하다.
- **오답 대상 복습:** 같은 자료 범위에 오답만 모드를 채운 설정 화면으로 이동한다. 대상은 이번 시험의 오답뿐 아니라 해당 자료의 현재 누적 오답 대상이다.
- **시험 기록 보기:** [기록 목록](05_시험기록조회.md)으로 이동한다.

현재 오답 대상이 없으면 복습 대상이 없음을 표시한다. 새 시험은 시작 버튼을 눌렀을 때 생성하고, 결과를 다시 여는 것만으로 학습 횟수를 늘리지 않는다. 결과 화면에서는 답변과 판정을 조회한다.
