# 화면 흐름 검토 사례

상태: 화면 문서의 연결을 점검하기 위한 사례다. 실제 화면 구현과 앱 테스트는 진행하지 않았다.

| 상황 | 기대 화면과 동작 |
| --- | --- |
| 처음 두 자료를 모두 선택하고 일반·전체 출제 시작 | 자료 선택에서 254문항 범위를 확인하고 초기 저장 후 한 문항씩 표시 |
| 오답만 모드인데 대상이 없음 | 자료 선택에 머물며 범위나 모드 변경 안내. 새 시험 생성 안 함 |
| 10문항 중 1문항을 비워 최종 제출 시도 | 제출 확인에 미응답 번호 표시. 계속 작성하거나 그대로 제출해 해당 문항을 오답 처리 |
| 오답 대상 문항이 연속 2회 정답인 상태에서 다시 정답 | 결과 판정은 정답이고, 완료 결과를 반영한 현재 상태는 오답 대상에서 제외 |
| 답변 작성 후 저장 실패 | 입력 내용을 유지하고 저장 실패와 재시도 표시. 저장 완료로 표시하지 않음 |
| 시험을 중단한 뒤 원본 자료가 제거됨 | 기록에서 저장된 질문과 답변 및 위치로 이어 풀기. 문항을 다시 뽑지 않음 |
| 최종 제출 후 채점이나 저장 중 앱 중단 | 기록에서 답변 수정 없이 처리 재개. 같은 시험으로 처리하고 횟수 중복 집계 방지 |
| 과거 완료 시험을 다시 열었는데 이후 학습 상태가 달라짐 | 응시 당시 판정은 유지하고, 현재 오답 대상과 횟수는 별도로 표시 |

화면 전환은 [화면 연결](00_화면연결.md), 저장 성공과 처리 상태의 실제 보장은 저장 방식 설계에서 검증한다. 구현 시에는 이 사례의 기대 결과와 실제 화면 동작을 비교한다.
