# 학습 자료 선택과 시험 설정 화면

상태: 자료 선택·3가지 출제 모드·후보 수·문제 수와 표시 순서 연결 완료. 자료 교환 진입은 후속 단계다. 검증은 [기록과 오답 재학습 결과](../작업계획/10_기록조회와오답재학습.md)를 따른다.

시작 화면에서 학습 자료와 출제 조건을 선택하고 새 시험을 만든다. 초기 목록은 [등록한 두 묶음](../../data/initial/catalog.json)을 사용한다.

## 표시와 입력

| 영역 | 내용 |
| --- | --- |
| 자료 목록 | Android 107문항과 일반 CS 147문항의 이름·문항 수·선택 여부 |
| 선택 범위 | 하나 또는 여러 묶음 선택. 선택 순서를 표시하고 위·아래로 변경 |
| 기록 반영 | 일반·오답 우선·오답만 중 선택 |
| 문제 수 | 전체 또는 직접 지정. 현재 조건으로 가능한 문항 수 표시 |
| 표시 순서 | 무작위 또는 순서대로 선택 |
| 시작 전 안내 | 짧은 답 입력과 등록된 정답 표기의 완전 일치 채점, 제출 후 결과 공개 안내 |
| 주요 동작 | 시험 시작과 시험 기록 보기 |

초기 기본값은 자료 미선택·10문항 지정·무작위·일반이다. 설정 화면 안에서 돌아오는 경우 입력한 조건을 유지한다. 이전 결과에서 새 시험 설정으로 진입하면 해당 시험의 설정을 채우되 시작 전에 변경할 수 있게 한다.

## 시작 처리

1. 선택 범위와 기록 반영 모드로 출제 후보를 확인한다.
2. 전체 선택 또는 지정한 문제 수가 유효한지 확인한다.
3. 시험 시작을 누르면 문항을 선택하고 순서를 고정하며, 당시 자료명과 문항 내용을 보존한다.
4. 초기 저장이 성공하면 [시험 진행](02_시험진행.md)으로 이동한다. 준비 중에는 시작 버튼의 중복 입력을 막는다.

여러 묶음의 순서대로 출제는 선택한 묶음 순서와 묶음 안의 문항 순서를 따른다. 전체 출제의 범위는 [재출제 모드](<../../공통 개발 문서/상세설계/학습규칙/04_재출제.md>)에 따른 후보 전체다.

## 빈 범위와 오류

자료를 선택하지 않았거나 후보가 없으면 시작할 수 없다. 오답만 모드에 대상이 없으면 다른 모드나 자료를 선택하도록 안내한다. 오답 우선에 대상이 없으면 일반 문항으로 구성됨을 알린다.

지정한 문제 수가 후보보다 많거나 1 미만이면 가능한 범위를 표시하고 수정을 요청한다. 선택한 학습 데이터의 읽기나 검증에 실패하면 해당 자료의 오류와 재시도를 안내한다. 보충 정보가 없다는 이유만으로 출제를 막지 않는다.

시험 기록 보기는 [시험 기록 조회](05_시험기록조회.md)로 이동한다. 새 자료의 파일 선택과 적용 미리보기는 [자료 교환](01_1_자료교환.md)으로 진입한다.
