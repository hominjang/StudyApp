# 한 문항씩 푸는 시험 화면

상태: 초기 설계 기준. 사용자 요구와 이번 작업의 구현 기준을 함께 반영했다.

현재 문항의 질문과 답변 입력란을 표시한다. 최종 제출 전에는 정답과 허용 표기 및 해설을 공개하지 않는다.

## 화면 구성

| 영역 | 표시와 동작 |
| --- | --- |
| 진행 정보 | 시험 자료명, 현재 문항 번호와 전체 수, 응답한 수와 미응답 수 |
| 질문 | 현재 문항의 질문 전체 표시 |
| 답변 | 한 줄 입력. 입력 내용을 자동 정리하거나 대소문자를 바꾸지 않음 |
| 문항 이동 | 이전·다음 버튼과 번호 목록. 번호에는 응답·미응답과 현재 위치만 표시 |
| 저장 상태 | 저장 중·저장 완료 시각·저장 실패와 재시도 표시 |
| 시험 동작 | 최종 제출과 저장 후 나가기 |

화면의 문항 번호는 1부터 시작하고 본문과 번호 목록에서 같은 번호를 사용한다. 번호 목록에서는 정답·오답 색상이나 정답 힌트를 표시하지 않는다. 긴 질문은 읽을 수 있게 줄바꿈하되 저장된 질문과 입력 답변의 문자열은 바꾸지 않는다.

## 답변과 이동

- 제출 전에는 이전 문항으로 돌아가 답변을 수정할 수 있다. 미응답인 채로 다른 문항으로 이동할 수도 있다.
- 답변과 현재 문항 위치가 바뀌면 자동 저장한다. 첫 문항의 이전과 마지막 문항의 다음은 사용할 수 없게 한다.
- 마지막 문항에 도달해도 자동 제출하지 않는다. 최종 제출 버튼으로 [제출 확인](02_1_제출확인.md)에 진입한다.
- Enter 입력만으로 시험을 최종 제출하지 않는다. 한글 조합 확정과 화면 동작이 충돌하지 않게 한다.

## 나가기와 저장 실패

저장 후 나가기는 최신 상태를 저장한 뒤 자료 선택으로 돌아간다. 이미 저장 중이면 완료를 기다리고, 실패하면 입력을 유지한 채 재시도와 계속 작성을 제공한다.

창을 정상적으로 닫을 때도 같은 저장 절차를 적용한다. 저장 실패 상태에서 종료를 선택하면 저장되지 않은 최근 입력이 복원되지 않을 수 있음을 안내한다. 강제 종료 후에는 마지막 저장 성공 상태에서 [이어 풀기](04_진행시험재개.md)를 제공한다.

자동 저장은 [500ms 대기와 최대 2초 간격의 요청](../저장방식/04_진행상태저장과복구.md)을 적용한다. 입력과 판정의 연결은 [문항별 응답 데이터](<../../공통 개발 문서/상세설계/데이터/02_2_문항별응답.md>)를 따른다.
