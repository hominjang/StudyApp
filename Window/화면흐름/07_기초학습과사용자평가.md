## 기초 문항의 오답노트 편입

결과·회고에서 상위 문항의 기초 부분을 모르면 연결된 기초 문항을 선택해 ‘오답노트에 추가’한다. 추가 완료 상태를 표시하고, 다음 학습은 기존 학습 시작 화면의 오답 우선·오답만으로 진행한다. 별도 기초 학습 모드나 기초 전용 새 시험 준비 화면을 만들지 않는다.

상위 문항의 판정·점수·제출 답변은 바꾸지 않는다. 기초 문항을 실제로 틀린 응시 기록도 생성하지 않고, 사용자가 복습 대상으로 추가한 것으로 구분한다. 이미 추가된 문항의 반복 조작이 중복 등록이나 정답 횟수 변경으로 이어지지 않게 한다.

연결된 묶음이나 문항이 없으면 추가할 수 없음을 안내한다. 임의 질문·정답·빈 응시를 만들어 대신하지 않는다. 다음 출제에서도 사용자가 선택한 자료 범위·문제 수·표시 순서를 적용하며, 현재 시험의 문항·순서·개수는 바꾸지 않는다.

추가할 기초 문항이 속한 자료를 표시한다. 다른 묶음의 문항을 추가한 경우에도 이후 출제에는 사용자가 그 자료를 선택해야 하며, 현재 선택 범위를 자동으로 늘리지 않는다.

## 풀이와 제출

새 형식을 지원한 뒤에는 유형에 따라 단답형 한 줄 입력과 서술형 여러 줄 입력을 구분한다. 답변·현재 위치는 자동 저장하고 최종 제출 전 정답·참고 답안·핵심 내용은 숨긴다. 전체 제출 전 미응답을 안내하고, 제출 후에는 답변 원문을 잠근다.

제출 처리 중 오류와 사용자 평가 대기는 다른 화면 상태로 다룬다. 평가를 나중으로 미뤄도 기록에서 다시 열 수 있고 다른 학습을 시작할 수 있게 한다. 시험 상태와 평가 상태를 별도로 둘지, 순번을 언제 부여할지는 확장 1에서 결정한다.

## 평가와 회고

1. 제출 답변과 출제 당시 참고 답안·핵심 내용을 함께 확인한다.
2. 사용자가 정답·부분정답·오답을 선택하고 저장한다. 저장 전 선택은 유효 평가로 표시하지 않는다.
3. 결과 요약은 사용자 확정에 따라 정답·부분정답·오답·미평가 개수를 표시한다. 평가된 수와 미평가 수를 구분하며 숫자 배점·부분정답 점수 환산·혼합 합계는 초기 범위에 넣지 않는다.
4. 나중에 기록에서 평가를 정정할 때 원래 평가·현재 평가·정정 여부를 구분한다. 원문 답변을 수정하거나 새 시험으로 복제하지 않는다.
5. 정정 저장 후 결과 요약·기록 목록·오답 대상 상태를 새로 조회한다. 버전 충돌이나 실패면 이전 유효 평가를 유지하고 다시 확인하도록 안내한다.

미응답과 단답형 자동 판정의 정정 허용 범위는 정책 확정 뒤 적용한다. 이번 응답의 평가 정정과 자료의 허용 표기 추가는 별도 동작이다. 평가 대기와 부분정답 필터는 세부 정책에 맞춰 구체화한다.

현재 exe는 위 확장 화면을 제공하지 않는다. 기존 여러 줄 답변을 복원하는 보완은 서술형 지원과 별개이며 [보완 결과](../작업계획/13_기존답변복원보완.md)에서 확인한다.
