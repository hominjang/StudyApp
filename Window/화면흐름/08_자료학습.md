# 질문·답 자료 학습 화면

상태: 2026-11-27 구현. 시험과 별도로 현재 학습 자료의 질문·답을 함께 읽는다. [사용 안내](../사용안내/02_자료학습.md)

| 영역 | 동작 |
| --- | --- |
| 진입 | 왼쪽 **자료 학습**. 시험 진행 중에는 진입을 막고 저장 후 나가기를 먼저 사용 |
| 자료 범위 | 전체 자료 또는 등록된 자료 하나. 시험 설정의 선택 범위와 독립 |
| 검색 | 질문에 검색 문자열이 포함된 항목만 표시. `%`, `_`, 따옴표는 일반 문자. 검색 버튼/Enter로 적용 |
| 내용 | 질문·단답 대표 정답/허용 표기 또는 서술형 참고 답안/핵심 내용·선택 해설을 처음부터 표시 |
| 편집 | 정답·해설 수정 → 내용 입력 → 수정 저장 또는 취소. 편집 중 메뉴/검색/페이지 이동과 종료는 보류 |
| 순서·이동 | 자료 순서와 문항 순서, 20개씩 페이지 이동. 범위/검색 변경 시 첫 페이지 |
| 빈 목록·오류 | 연결 안 됨·자료 없음·검색 결과 없음·조회 오류를 구분. 오류는 같은 조건으로 다시 불러오기 |

다른 조회가 먼저 끝나더라도 현재 조건의 응답만 표시한다. 읽는 동안 이동·종료할 수 있고 학습 기록 저장을 기다릴 필요는 없다. 앱 재실행 후 읽던 위치 복원이나 읽음 기록은 만들지 않는다.

`browse_study_materials`는 DB 1/2 활성 자료만 읽고 시험·응답·평가·진도에 쓰지 않는다. 별도 `update_study_material`만 명시적으로 자료를 수정하며 기존 시험/학습 기록은 유지한다. [편집 계약](../구현설계/11_자료학습편집.md)을 따른다. 시험 작성 DTO와 시험 화면은 계속 최종 제출 전에 정답/판정을 표시하지 않는다. 저장한 미완료 시험이 있더라도 자료 학습은 별도로 사용할 수 있다.

DTO·조회 경계와 검증은 [자료 학습 결과](../작업계획/19_질문답자료학습.md)에 연결한다.
