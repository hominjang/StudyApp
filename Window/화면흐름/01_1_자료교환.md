# 학습 자료 가져오기와 내보내기 화면 흐름

상태: 초기 설계 기준. 사용자 요구와 이번 작업의 구현 기준을 함께 반영했다.

## 가져오기

1. 학습 JSON 파일과 선택적인 보충 JSON 파일을 고른다.
2. 검증이 끝나면 자료명과 문항 수, 신규 또는 갱신 여부, 추가·변경·비활성화될 문항 수를 표시한다.
3. 사용자가 적용하면 저장한다. 성공 후 자료 목록으로 돌아가고, 실패하면 기존 자료를 유지하며 오류를 표시한다.

검증 오류는 파일과 항목을 알려 수정 후 다시 선택할 수 있게 한다. 미리보기를 취소하면 자료를 바꾸지 않는다. 진행 중이거나 완료된 시험은 자료 갱신으로 바뀌지 않는다.

## 내보내기

자료 하나와 새 출력 폴더를 선택하고 학습 JSON과 보충 JSON을 함께 내보낸다. 기존 폴더를 덮어쓰지 않고 다른 이름을 안내한다. 성공하면 저장 위치를 표시하고, 실패하면 재시도할 수 있게 한다. 사용자 답변과 시험 기록은 이 파일에 포함하지 않는다.

파일 형식과 적용 범위는 [가져오기와 내보내기](../저장방식/03_가져오기와내보내기.md), 목록 복귀는 [자료 선택](01_데이터선택.md)을 따른다.
