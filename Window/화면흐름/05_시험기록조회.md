# 시험 기록 조회 화면

상태: 전체 기록·상태별 필터·완료 점수·과거 결과 조회와 미완료 시험 재개 구현. [수행 결과](../작업계획/10_기록조회와오답재학습.md)

현재 사용자의 시험을 조회하고 진행 상태에 맞는 화면으로 이동한다. 자료 선택과 결과 화면에서 시험 기록 보기로 진입한다.

## 목록 구성

자료명, 진행 상태, 문항 수, 저장 또는 완료 시각을 표시한다. 진행 중 시험에는 응답한 수, 완료된 시험에는 정답 수를 함께 표시한다. 제출 후 처리 중인 시험은 완료 결과와 구분한다.

전체·진행 중·처리 중·완료 필터를 제공한다. 전체 목록에서는 미완료 시험을 먼저 표시하고 마지막 저장 시각의 최신순으로 정렬한다. 완료된 시험은 완료 순번의 내림차순으로 정렬하며 완료 시각을 함께 표시한다. 완료 전에는 정답과 판정 결과를 보여주지 않는다.

| 시험 상태 | 주요 동작 |
| --- | --- |
| 진행 중 | 이어 풀기 |
| 최종 제출 후 처리 중 | 처리 재개 |
| 완료 | 결과 보기 |

표시할 자료명은 시험 시작 시 보존한 이름을 사용한다. 현재 자료 목록에서 제거된 자료도 보관한 시험을 조회할 수 있다.

## 빈 목록과 오류

기록이 없으면 안내와 새 시험 시작 경로를 표시한다. 읽기 실패는 기록 없음과 구분하고 재시도를 제공한다. 특정 기록의 오류는 해당 항목에 안내한다.

조회와 이동만으로 새로운 시험이나 문항별 정답 횟수를 만들지 않는다. 초기 버전은 기록 삭제와 확정 결과 수정 기능을 제공하지 않으며 재학습은 새 시험으로 남긴다.

진행 중 시험은 [시험 재개](04_진행시험재개.md), 완료된 시험은 [결과와 재학습](03_결과와재학습.md)으로 연결한다.
