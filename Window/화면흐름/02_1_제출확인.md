# 시험 최종 제출 확인

상태: 초기 설계 기준. 사용자 요구와 이번 작업의 구현 기준을 함께 반영했다.

시험 진행 화면 위에 제출 확인 창을 표시한다. 여기에서는 정답을 공개하지 않고 제출할 답변의 상태만 확인한다.

## 확인 내용과 선택

전체 문항 수와 응답 수 및 미응답 수를 표시한다. 미응답이 있으면 해당 문항 번호를 안내하고 그대로 제출할 경우 오답으로 기록됨을 알린다.

| 선택 | 처리 |
| --- | --- |
| 계속 작성 | 시험으로 복귀. 미응답 번호를 선택했다면 해당 문항으로 이동 |
| 최종 제출 | 최신 답변을 보존하고 제출을 확정한 뒤 자동 채점과 결과 저장 |

미응답이 없어도 최종 제출 전 확인 단계를 거친다. 확인 창을 닫으면 입력 가능한 시험 화면으로 돌아간다.

## 제출 후 처리

1. 최신 답변을 저장하고 최종 제출 상태를 확정한다. 저장에 실패하면 답변을 잠그거나 채점으로 넘어가기 전에 재시도를 안내한다.
2. 제출이 확정되면 답변을 잠그고 처리 중 화면을 표시한다. 제출 버튼의 중복 입력을 막는다.
3. 자동 채점과 결과 기록이 모두 완료되면 [결과 화면](03_결과와재학습.md)으로 이동한다.

처리 중에는 부분적인 정답과 판정 결과를 공개하지 않는다. 채점이나 저장이 실패하면 오류와 재시도 및 시험 기록으로 이동을 제공한다. 제출된 답변을 유지하고, 재시도하면 같은 시험의 처리를 이어간다.

제출 후 처리가 중단되어도 작성 화면으로 되돌려 답변을 수정하지 않는다. [시험 기록](05_시험기록조회.md)에서 처리 재개로 진입하며 새 시험을 만들지 않는다.

상태 전이는 [진행 저장과 재개](<../../공통 개발 문서/상세설계/학습규칙/03_1_진행저장과재개.md>), 판정은 [채점 규칙](<../../공통 개발 문서/상세설계/학습규칙/02_채점.md>)을 따른다.
