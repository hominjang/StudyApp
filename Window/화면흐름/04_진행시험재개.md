# 중단한 시험 이어 풀기

상태: 초기 설계 기준. 사용자 요구와 이번 작업의 구현 기준을 함께 반영했다.

시험 기록에서 진행 중 시험을 선택해 저장된 문항과 답변 및 위치를 복원한다. 기존 시험을 이어가는 동안 새 문제를 뽑지 않는다.

## 복원 흐름

1. [시험 기록](05_시험기록조회.md)에서 진행 중 시험의 이어 풀기를 선택한다.
2. 마지막 저장 시각과 저장된 응답 수를 표시하고 복원한다. 복원 중 중복 입력을 막는다.
3. 시험 식별자, 출제 순서, 문항 내용과 입력 답변 및 현재 위치를 그대로 불러온다.
4. [시험 진행](02_시험진행.md) 화면에서 나머지 답변을 작성한다.

복원한 답변을 수정할 수 있고 자동 저장도 이어진다. 현재 학습 자료나 오답 대상이 바뀌었어도 해당 시험의 문항과 순서 및 정답 기준을 새로 구성하지 않는다.

## 상태별 진입

| 선택한 시험 상태 | 이동 |
| --- | --- |
| 진행 중 | 저장된 위치에서 답변 작성 재개 |
| 최종 제출 후 처리 중 | 답변 수정 없이 [채점과 저장 처리](02_1_제출확인.md) 재개 |
| 완료 | [결과 조회](03_결과와재학습.md) |

## 복원 실패와 원본 누락

읽기에 실패하거나 저장된 문항이 불완전하면 오류와 재시도를 안내하고 원래 기록을 보존한다. 실패한 시험을 임의의 새 시험으로 대체하지 않는다. 기록 목록이나 자료 선택으로 돌아갈 수 있게 한다.

원본 학습 자료가 없어도 시험에 보존한 문항과 정답 및 입력 답변이 있으면 이어 풀 수 있다. 저장되지 않은 최근 입력까지 복원되었다고 표시하지 않는다.

복원 기준은 [진행 저장과 재개](<../../공통 개발 문서/상세설계/학습규칙/03_1_진행저장과재개.md>)를 따른다. 저장 구조와 실제 복구 절차는 저장 방식 설계에서 구체화한다.
