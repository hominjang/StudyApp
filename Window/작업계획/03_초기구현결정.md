# Windows 초기 구현 결정

공통 데이터와 학습 요구를 Windows 앱의 동작으로 구체화한 기준이다.

| 항목 | Windows 기준 | 경로 |
| --- | --- | --- |
| 기술 | React·TypeScript·Vite와 Tauri 2·Rust·rusqlite | [기술 선정](../구현설계/00_기술선정.md) |
| 새 시험 기본값 | 자료 미선택·10문항·무작위·일반 | [자료 선택](../화면흐름/01_데이터선택.md) |
| 다시 풀기 | 기존 설정을 채우되 시작 전 변경 가능 | [결과와 재학습](../화면흐름/03_결과와재학습.md) |
| 자동 저장 | 변경 후 500ms, 연속 입력 중 최대 2초마다 요청. 이동·종료·제출 시 즉시 저장 | [저장과 복구](../저장방식/04_진행상태저장과복구.md) |
| 기록 수정·삭제 | 초기 버전은 조회만 제공. 재학습은 새 시험으로 추가 | [기록 저장](../저장방식/02_학습기록저장.md) |
| 로컬 사용자 | 프로필 하나, 앱 인스턴스 하나. 별도 로그인 없음 | [저장 구성](../저장방식/00_저장구성.md) |
| 완료 처리 | SQLite 트랜잭션에서 완료 순번·판정·학습 상태 동시 확정 | [완료 처리](../저장방식/02_1_완료처리와중복방지.md) |
| 자료 교환 | JSON 1.0을 명시적으로 가져오고 외부 파일과 자동 동기화하지 않음 | [자료 교환](../저장방식/03_가져오기와내보내기.md) |

이 선택은 Android의 구현 기술이나 저장 간격을 정하지 않는다. 공통 학습 규칙은 [공통 설계 결정](<../../공통 개발 문서/작업계획/03_초기설계결정.md>)을 따른다. 실제 자료의 Git 제외는 [공통 관리 원칙](<../../공통 개발 문서/개발원칙/01_실제데이터와Git관리.md>)을 적용한다.

위 표는 현재 단답형 앱의 기준이다. 2026-11-26의 [확장 계획](12_학습방식확장계획.md)에서는 제출 원문을 보존하며 사용자 평가와 정정을 추가한다. 평가 대기·완료 순번·기록 이력·새 교환 형식은 구현 전에 별도 설계하며, 기존 DB와 명령은 아직 변경하지 않았다.
