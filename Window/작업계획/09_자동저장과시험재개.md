# 자동 저장과 시험 재개 구현 결과

작업일: 2026-11-25. 상태: 구현 진행 계획 4단계 완료.

아래는 4단계 완료 당시의 기록이다. 이후 완료된 기록 조회와 오답 출제는 [5단계 결과](10_기록조회와오답재학습.md)에서 확인한다.

## 변경 내용

답변·위치 변경 후 500ms 동안 추가 입력이 없으면 자동 저장한다. 연속 입력은 최대 2초 간격으로 저장 요청을 보내며, 이미 저장 중이면 최신 미전송 상태 하나만 유지한다. 문항 이동·저장 후 나가기·최종 제출과 정상 창 닫기에서는 최신 저장을 기다린다. 화면은 저장 예정·저장 중·최신 상태 저장 완료·저장 실패를 구분한다.

저장 요청에는 시험 ID·revision·전체 답변·현재 위치를 담는다. Rust는 프로필과 상태·답변 수·위치를 확인하고 높은 버전만 적용한다. 같은 버전의 같은 내용은 중복 저장하지 않고, 낮은 버전은 무시하며 같은 버전의 다른 내용은 충돌로 처리한다. 제출·완료된 시험에는 늦게 도착한 자동 저장을 적용하지 않는다.

학습 시작과 시험 기록 화면에 미완료 시험 목록을 연결했다. 목록은 시작 당시 자료명·저장 시각·문항 수·응답 수·저장 위치를 표시한다. 이어 풀기는 DB의 문항 스냅샷·순서·답변·위치·revision을 그대로 복원한다. 제출 후 처리 중인 시험은 답변을 잠그고 채점을 재개한다. 새 시험을 만들거나 문제를 다시 추출하지 않는다.

## 창 종료와 오류

Tauri 창 닫기 요청을 가로채 현재 시험의 저장이나 제출 상태를 확인한다. 최신 저장이 성공해야 창을 닫으며, 실패하면 창과 입력을 유지하고 오류·재시도를 표시한다. 종료 전 저장 기능의 준비가 끝나기 전에는 새 시험과 재개를 시작하지 않는다. 최종 제출도 자동 저장 요청을 정리한 뒤 확정한다.

강제 종료나 전원 차단은 마지막 COMMIT까지만 복원한다. 아직 저장하지 않은 최근 입력까지 복구되었다고 표시하지 않는다. 작성 중 저장 실패를 제출 성공이나 최신 저장 완료로 안내하지 않는다.

타이머 테스트는 가상 시계를 사용해 500ms와 2초, 저장 지연 중 최신 상태 병합, 오류 후 동일 버전 재시도, stale·locked의 저장 완료 표시 금지와 폐기된 화면의 지연 응답 차단을 확인한다. Rust 테스트는 낮은 버전·동일 버전 충돌, 저장 전체 롤백, 원문·스냅샷 복원, 제출 이후 저장 차단과 처리 재개를 확인한다.

Windows 오류·종료 검증은 .tools의 가상 자료와 별도 DB에서 수행했다. 기존 실제 자료와 사용자 DB에 검증용 시험을 추가하지 않았다. 실제 문항·정답·답변은 문서와 로그에 남기지 않는다. 실제 Windows 한글 IME의 연속 조합·다양한 DPI·배포 설치 환경 검증은 7단계에서 추가한다.

## 실행과 다음 작업

실행·테스트 명령은 [시험 구현 결과](08_시험출제와채점.md#실행과-검증)를 사용한다. `run-web.ps1 -Task test`는 공백과 자동 저장 테스트를 함께 실행한다. Rust 테스트는 [자료 연결 결과](07_자료등록과저장소연결.md#실행-방법)의 환경 설정 후 기본 테스트와 `-- --ignored`로 실제 자료용 테스트를 별도로 실행한다.

다음 5단계는 완료된 시험의 기록 목록·필터·결과 재조회와 오답 우선·오답만 출제다. 현재 미완료 시험 목록과 처리 재개는 사용할 수 있지만 완료된 시험 목록과 오답 출제 모드는 아직 연결하지 않았다.
