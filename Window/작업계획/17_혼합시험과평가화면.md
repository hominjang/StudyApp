## Windows 창 검증

computer-use로 별도 식별자 `com.hominjang.studyapp.mixedqa`와 `.tools/mixed-ui-qa`의 가상 자료/DB만 사용했다. 개발 서버 연결이 유지되지 않아, 빌드한 frontendDist를 내장한 debug 실행(`tauri/custom-protocol`)으로 검증했다. 배포 exe나 사용자 저장 위치를 바꾸지 않았다.

- 가상 3문항의 자료 선택·전체/순서대로 출제·한 줄/여러 줄 값 입력·문항 이동·자동 저장·전체 제출·결과 공개 확인.
- 최초 결과 정답 2·미평가 1 확인. 앱 재실행 후 기록에서 같은 결과와 여러 줄 답변 재조회.
- 별도 가상 DB의 실패 트리거로 평가 저장 실패 주입. 자동 평가 이력 2개·성공 요청 0개·미평가 1개 유지 확인.
- 실패 트리거 제거 후 같은 요청 재시도로 부분정답 1개 저장. UI 오류·변경 보류·재시도와 개수 갱신 확인.
- 기초 문항 수동 편입 후 시험 수 1개와 평가 개수 유지, 수동 복습 이벤트 1개 생성 확인.
- 서술형을 정답으로 정정한 뒤 정답 3개·부분정답/미평가 0개, 수동 복습 대상 1개 유지 확인. 현재 오답 학습 준비에서 후보 1개 표시 확인.
- 정상 종료 후 가상 DB 무결성 통과. 최종 시험 1개·평가 이력 4개·성공 요청 3개·수동 복습 이벤트 1개·여러 줄 응답 1개. 실패 트리거 잔존 0개.

값 입력은 접근성 편집 API로 수행했다. 실제 키보드 IME 조합·Enter·클립보드 붙여 넣기를 검증한 것으로 보고하지 않는다. 보고에는 가상 자료의 개수와 통과 여부만 기록하고 실제 문항/답변은 옮기지 않았다.

## 남은 적용 작업

기존 사용자 DB 1을 DB 2로 활성 교체하는 실행/복원 절차는 아직 없다. 실제 자료의 기초·서술형 보강과 배포 exe도 남아 있어 기존 배포본에서 새 화면을 사용할 수 있다고 안내하지 않는다. 다음은 정책 최종 점검 → 활성 교체/복원 검증 → 소규모 실제 자료 보강 → 사용자 IME/업데이트 확인과 exe 재생성이다.

문서 경로 검사 결과 JSON은 검사 실행으로 갱신했다. 실제 자료 검사는 ignore 여부와 개수만 확인했으며 내용을 열거나 수정하지 않았다. 실제 자료용 ignored 검사·활성 사용자 DB 전환·실제 규모 성능은 미확인/미실행이다.
