# 배포 앱의 자료 추가·갱신

작성일: 2026-11-27. 상태: JSON 가져오기 화면·Rust 명령 구현·가상 자동 검사·Windows 파일 선택/취소→미리보기→추가→출제 검증·배포 실행 폴더 생성 완료. 실제 사용자 DB는 열거나 전환하지 않았고 stage·commit·push는 하지 않았다.

## 구현 범위

| 영역 | 결과 |
| --- | --- |
| 화면 | 자료 추가 메뉴·학습/선택 보충 파일 선택·내용 확인·미리보기·명시적 적용·양식 다운로드 |
| 검증 | 기존 1.0/2.0 공통 파서 재사용. ID·문항 중복·필수 필드·고정 공백·단답 정답 4단어·묶음 연결 검사 |
| 읽기 경계 | `choose_import_file`의 Windows 대화상자가 고른 파일만 Rust에서 읽음. 각 16 MiB, UTF-8 오류 거부, 파일 BOM만 제거하고 JSON 문자열 유지. 파서에서도 크기 재검사 |
| 저장 | 미리 읽은 DTO와 토큰을 DB 작업 큐 안에서 보관. 적용 시 자료 revision 재확인, 단일 트랜잭션 갱신·실패 롤백 |
| 중복과 재시도 | 같은 내용은 no-op. 같은 앱 실행의 성공 토큰 재시도는 기존 결과 반환. 재실행 후 다시 선택해도 내용 비교로 중복 추가 방지 |
| 보존 | 자료 목록 갱신만 수행. 진행·완료 시험 스냅샷·응답·학습 상태·평가 이력은 수정하지 않음 |
| 호환 | 기존 DB 1에는 JSON 1.0만 허용. 신규 DB 2는 1.0/2.0. 자동 DB 전환·사용자 파일 덮어쓰기 없음 |

React `ImportWorkspace` → `bridge/transfer.ts` → `preview_import`/`apply_import` → `DbWorker`의 단일 큐 → `RuntimeStore`의 현재 연결 → `transfer.rs` 순서로 연결했다. 가져오기 화면의 저장 중/결과 미확인 상태는 이동·종료 전에 확인하며, 같은 토큰으로 재시도한다. 취소와 파일 변경은 적용 전 미리보기만 폐기한다. 새 자료의 순서는 현재 자료 다음에 배치한다.

같은 자료 ID는 전체 목록 갱신이며 빠진 활성 문항은 비활성화한다. 문항 순서 교환의 유일 인덱스 충돌을 피하기 위해 갱신 자료의 문항을 먼저 비활성화하고 입력 순서로 upsert한다. 보충 정보·연결 목록의 생략/교체 기준과 사용자 절차는 [사용 안내](../사용안내/01_문제자료추가.md)에 분리했다. 독립 복제·내보내기·백업·복구는 이번 범위에 포함하지 않는다.

## 실행 파일과 Windows 확인 범위

새 실행 위치는 `Window/artifacts/StudyApp-0.1.0-windows-x64-20261127T011452778Z/StudyApp.exe`다. `initial-data`와 실행 안내를 포함한 폴더 전체를 사용한다. 이전 실행 폴더를 덮어쓰지 않았으며 현재 사용자 기록을 복사하거나 열지 않았다. 새 exe와 초기 자료는 Git 제외 확인을 마쳤다.

별도 식별자 `com.hominjang.studyapp.importqa`·가상 자료/DB `.tools/import-ui-qa`의 debug 앱에서 다음을 확인했다. 실제 사용자 저장 위치와 배포 exe를 열어 검증한 것은 아니다.

- 자료 추가 메뉴·Windows 파일 선택 창 표시, 취소 후 자료 변경 없이 복귀.
- 가상 1.0 학습 파일 선택 → 미리보기의 신규 1문항·추가 1·변경/비활성화 0 확인 → 명시적 추가 적용.
- 목록이 1묶음/1문항에서 2묶음/2문항으로 갱신되고 추가한 묶음이 선택됨.
- 추가한 자료의 전체 출제로 시험을 시작해 해당 1문항이 표시됨.
- 정상 종료 후 가상 DB를 읽기 전용으로 확인: 묶음 2개·활성 문항 2개·진행 중 시험 1개. 무결성 통과·외래 키 오류 0개. 검증 창은 닫았다.

양식의 Windows 다운로드·화면에서의 보충 파일 선택/갱신/실패 재시도 전체 조작·배포 exe 자체의 화면 조작은 미확인이다. 해당 처리의 Rust 저장/검증과 화면 정적 렌더는 위 자동 검사로 구분한다. 한글 경로는 파일 이름 편집 API로 지정했으며 실제 IME 입력 검증으로 보고하지 않는다.

## 사용자 확인

- [ ] 새 실행 폴더의 exe에서 **자료 추가** 메뉴가 보인다.
- [ ] 준비한 1.0 자료를 확인·추가하고 학습 시작 목록에서 출제한다.
- [ ] 같은 자료를 다시 가져오면 중복 추가하지 않는다.
- [ ] 같은 자료 ID를 갱신할 때 빠진 문항의 비활성화 수를 확인한다.
- [ ] 기존 시험의 문항·답변·판정과 이어 풀기 상태가 유지된다.
- [ ] 잘못된 ID·5단어 정답·다른 묶음의 보충 파일은 거부된다.
- [ ] 기존 DB 1에서 2.0 거부 안내가 나오고 기존 기록은 유지된다.

실제 자료/사용자 DB로 위 체크를 대신 수행하지 않는다. 다른 PC·설치 프로그램·서명·대규모 자료와 실제 한글 입력기는 미확인이다. 다음은 기존 DB 활성 전환/복원과 자료 내보내기·백업/복구다.
