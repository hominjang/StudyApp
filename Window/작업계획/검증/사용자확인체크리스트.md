# 사용자 확인 체크리스트

갱신일: 2026-11-25. 대상: 1~5단계가 구현된 Windows 앱. 아래 체크는 사용자가 직접 확인한 뒤 표시한다. 자동 테스트와 개발 중 화면 검증은 [구현 결과](../10_기록조회와오답재학습.md)에 별도로 기록한다.

## 실행 준비

- [ ] 열려 있는 StudyApp을 정상 종료한다. 저장소 루트의 PowerShell에서 아래 명령으로 검증용 앱을 실행한다.

```powershell
$env:STUDYAPP_DB_DIR = Join-Path (Get-Location) '.tools/user-check-05'
& ./Window/scripts/run-web.ps1 -Task tauri:dev
```

이 명령은 평소 개발 DB와 분리된 검증용 DB를 사용한다. 같은 경로로 재실행하면 검증 기록이 유지된다. 처음부터 다시 확인하려면 폴더 이름을 다른 이름으로 지정한다. 이 PowerShell 창을 닫으면 해당 환경 변수 설정은 끝난다. 실제 학습 자료 준비와 도구는 [실행 안내](../07_자료등록과저장소연결.md#실행-방법)를 따른다.

- [ ] Windows 앱에서 자료 2묶음·254문항이 보인다. 브라우저 미리보기 대신 Windows 앱을 사용한다.
- [ ] 새 검증 DB의 시험 기록은 비어 있고, 자료의 오답 대상 수는 0이다.

## 오답 한 문항 만들기

- [ ] 자료 하나·일반 학습·문제 수 1·순서대로를 선택한다. 시작 전에는 정답이 보이지 않는다.
- [ ] 빈 답변으로 제출 확인을 열면 미응답 1문항을 안내한다. 최종 제출하면 오답·미응답으로 기록된다.
- [ ] 결과의 대표 정답을 확인한다. 학습 화면으로 돌아오면 해당 자료의 오답 대상 수가 1이다.

이후에는 같은 자료 범위를 사용한다. 정답·문항 내용은 이 체크리스트나 오류 보고서에 옮기지 않는다.

## 기록과 상태별 이동

- [ ] 시험 기록의 완료 필터에 방금 시험이 보인다. 문항 수·정답 수·완료 시각과 결과 보기가 표시된다.
- [ ] 결과를 여러 번 다시 열어도 시험이 추가되거나 오답 대상 수·연속 정답 횟수가 늘지 않는다.
- [ ] 학습 화면에서 오답 우선·문제 수 2·순서대로 시험을 시작한다. 기존 오답과 나머지 문항이 함께 포함된다. 확인 후 **제출하지 않고 저장 후 나가기**를 누른다.
- [ ] 기록의 진행 중 필터에는 위 시험이 보이고 점수는 보이지 않는다. 전체 목록에서는 미완료 시험이 완료 기록보다 먼저 나온다.
- [ ] 이어 풀기를 누르면 같은 문항·순서·답변·위치로 돌아간다. 저장 후 나가도 시험 개수가 중복 증가하지 않는다.
- [ ] 완료·진행 중·처리 중·전체 필터를 바꾸면 해당 상태만 보인다. 없는 상태는 빈 목록 안내를 표시한다. 처리 중 시험이 생기면 입력 수정 대신 처리 재개로 연결된다.

오답 우선은 문항을 고르는 우선순위다. 최종 표시 순서는 무작위·순서대로 설정을 따른다.

## 출제 범위와 개수

- [ ] 오답만 모드에서는 현재 오답 한 문항만 후보가 된다. 전체 출제를 선택하면 1문항이 출제된다.
- [ ] 오답만에서 문제 수 2를 지정하면 범위 오류를 안내하고 시작할 수 없다. 1 또는 전체로 바꾸면 시작할 수 있다.
- [ ] 다른 자료만 선택한 오답만 모드에는 원래 자료의 오답이 섞이지 않는다. 대상이 없으면 안내하고 시작을 막는다.
- [ ] 자료·모드를 빠르게 바꿔도 마지막 선택의 후보 수를 보여준다. 무작위 출제에서는 같은 시험 안에 동일 문항이 중복되지 않는다.

## 3회 연속 정답과 과거 결과

- [ ] 원래 자료의 오답만·전체·순서대로 시험에서 앞서 확인한 대표 정답을 정확히 입력해 제출한다. 정답이어도 연속 1/3회로 오답 대상에 남는다.
- [ ] 같은 문항을 새 시험에서 다시 맞히면 2/3회로 남는다.
- [ ] 새 시험에서 세 번째 연속 정답을 맞히면 오답 대상에서 제외되고, 오답만 후보가 0이 된다.
- [ ] 처음 틀렸던 시험을 기록에서 열면 당시 오답·미응답 판정과 점수는 그대로다. 현재 학습 상태는 오답 대상 아님으로 표시된다.
- [ ] 추가 확인: 일반·1문항·순서대로에서 같은 문항을 다시 틀리면 오답 대상으로 재편입되고 연속 횟수는 0이다. 이후 `정답 → 오답`이면 1에서 다시 0으로 초기화된다.

## 재실행과 입력 보존

- [ ] 작성 중 답변을 입력하고 저장 완료 후 앱을 정상 종료한다. 재실행 후 이어 풀면 같은 위치와 답변을 복원한다.
- [ ] 완료 기록과 현재 오답 대상 수가 앱 재실행 후에도 유지된다.
- [ ] 답변 입력란에서 Enter를 눌러도 줄이 바뀌지 않고 시험이 제출되지 않는다. 한글 조합 중 Enter도 같다.
- [ ] 기록에서 과거 결과를 열었다가 학습 시작으로 돌아와도, 미리 바꿔 둔 자료·문제 수·학습 방식이 그대로 남아 있다.
- [ ] 정답 앞뒤에 공백을 더해 제출하면 완전 일치하지 않아 오답이다. 결과의 공백 문자 표시로 차이를 확인할 수 있다.
