프로젝트 루트에서 Python 3의 표준 `sqlite3`를 사용할 수 있는 환경으로 실행한다.

```powershell
python Window/작업계획/검증/verify_design.py
python Window/작업계획/검증/verify_schema.py
python "공통 개발 문서/작업계획/검증/verify_links.py"
```

현재 Anaconda 환경에서 `_sqlite3` DLL을 못 찾으면 해당 프로세스의 PATH 앞에 `C:\Users\Homin\anaconda3\Library\bin`을 추가한다. 영구 시스템 설정은 바꾸지 않는다. 모델은 메모리 DB와 임시 백업 파일을 사용하며 앱의 실제 저장소를 생성하거나 변경하지 않는다.

실제 자료는 Git에서 제외되어 있으므로 로컬 data가 없는 환경에서는 두 SQLite 검사 전에 자료를 준비해야 한다. 검사 결과에는 문항 내용과 정답을 저장하지 않는다.
