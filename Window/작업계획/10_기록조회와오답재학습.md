# 시험 기록 조회와 오답 재학습 구현 결과

작업일: 2026-11-25. 상태: 구현 진행 계획 5단계 완료.

## 구현 범위

시험 기록에 전체·진행 중·처리 중·완료 필터를 연결했다. 목록은 시험 당시 자료명·상태·문항 수·저장 또는 완료 시각을 표시하며, 완료된 시험에만 정답 수와 비율을 보여준다. 미완료는 마지막 저장 시각의 최신순으로 먼저 표시하고, 완료 기록은 완료 순번의 내림차순으로 표시한다. 목록에서 이어 풀기·처리 재개·과거 결과 보기를 실행한다.

일반·오답 우선·오답만 모드를 모두 연결했다. 오답 우선은 오답 대상을 먼저 선택하고 부족하면 일반 문항으로 보충한다. 그다음 무작위 또는 원래 자료 순서를 적용한다. 오답만은 선택 범위의 현재 오답 대상만 후보로 삼는다. 전체 출제의 범위도 해당 모드의 후보다. 비활성 문항과 다른 자료의 오답은 제외한다.

preview_candidates가 현재 프로필의 활성 문항과 오답 상태로 후보 수를 조회하고, start_exam은 쓰기 트랜잭션에서 다시 확인한다. 오래된 후보 조회·기록 필터 요청은 현재 선택을 덮지 않으며, 후보 확인 중에는 시험 시작을 막는다. 대상 없음·후보보다 많은 문제 수는 안내하고 새 시험을 생성하지 않는다.

결과에서 같은 설정으로 새 시험을 준비하거나 원래 자료 범위의 현재 누적 오답 대상을 복습할 수 있다. 현재 자료 목록에 없는 자료는 안내하고 남은 범위를 다시 확인하게 한다. 과거 질문·답변·정답·판정은 스냅샷을 사용하고, 현재 오답 대상과 연속 정답 횟수는 별도로 조회한다. 조회만으로 학습 집계는 변경하지 않는다.

새 테스트는 원래 자료 순서에 따른 선택, 주입한 난수 공급원으로 선택 우선순위와 표시 순서를 구분하는 사례, 오답 부족 시 보충·대상 없음·개수 초과, 자료/문항 복합 식별과 비활성 제외, 필터·완료 순번 정렬·미완료 점수 비공개, 중간 오답 초기화·3회 해제·재편입과 과거 결과 불변을 포함한다.

Windows 검증은 .tools의 가상 자료와 별도 DB로 수행했다. 실제 자료용 테스트는 임시 DB를 사용하며 평소 학습 기록에 검증용 시험을 추가하지 않는다. 실제 문항·정답·답변은 문서와 로그에 기록하지 않는다.

## 독립 검증 후 수정

2026-11-25에 1~5단계를 독립 검증했다. 자동 테스트와 가상 자료 시나리오 6개는 통과했고 차단 결함은 없었다. 발견한 5건은 아래와 같이 고쳤다.

| 발견 사항 | 수정 |
| --- | --- |
| 실행 안내의 `pwsh -File` 명령이 PowerShell 7이 없는 PC에서 실패 | 체크리스트와 작업 결과·빌드 문서의 명령을 `& ./Window/scripts/run-web.ps1 -Task …`로 변경 |
| 여러 줄 입력란이라 Enter가 줄바꿈으로 답에 들어가 정답도 오답 처리 | 답변을 한 줄 입력으로 변경. Enter는 줄바꿈을 넣지 않고 제출하지도 않음 |
| 손상된 시험 하나가 기록 목록 전체와 학습 시작 화면의 자료 목록을 막음 | 기록·미완료 목록은 해당 행에만 오류를 표시하고, 자료 목록과 미완료 목록을 따로 불러옴 |
| 기록에서 결과를 열면 학습 시작 화면의 설정이 그 시험 설정으로 바뀜 | 이어 풀기·결과 보기에서는 설정을 바꾸지 않음 |
| 오답 우선에 대상이 없을 때 안내 문구 없음 | "현재 오답 대상이 없어 일반 문항으로 구성해요" 표시 |

수정 후 화면 로직 테스트 11개, TypeScript·Vite 빌드, Rust 기본 테스트 42개가 통과했다. 새 테스트는 손상된 진행 중·완료 기록이 해당 행에만 오류로 표시되고 다른 기록과 순서가 유지되는지 확인한다. 한 줄 입력과 안내 문구는 코드로만 확인했으며, 실제 Windows 화면과 한글 입력기 동작은 [사용자 체크리스트](검증/사용자확인체크리스트.md)로 확인한다.

정답 단어 수는 공통 문서에서 보조 지표였지만, 런타임 검증은 4단어를 넘으면 자료 등록을 거부했다. 2026-11-26에 4단어 상한을 가져오기 형식 규칙으로 확정했다. 구현은 그대로 두고 공통 [문항 작성](<../../공통 개발 문서/상세설계/데이터/04_단답형문항작성.md>) 기준을 이에 맞췄다.
