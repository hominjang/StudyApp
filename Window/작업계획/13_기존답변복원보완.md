# 기존 여러 줄 답변 복원 보완

작업일: 2026-11-26. 상태: 구현·자동 테스트·가상 자료의 Windows 화면 검증 완료. 사용자 요청에 따라 권장한 원문 복원 방식을 적용했다. 서술형과 사용자 평가 기능은 아직 구현하지 않았다.

## 바뀐 동작

새 단답형과 줄바꿈 없는 답변은 기존 한 줄 input을 사용한다. CR 또는 LF를 포함한 기존 답변은 여러 줄 textarea로 표시하고 줄바꿈도 채점에 반영된다는 안내를 제공한다. 수정하지 않은 답변은 원문 그대로 저장·제출한다.

textarea가 표시하는 줄바꿈과 저장 원문을 분리한다. 표시에는 LF를 사용하지만, 편집한 구간만 원문에 반영해 바꾸지 않은 CR·CRLF를 자동으로 LF로 덮어쓰지 않는다. 사용자가 삭제한 줄바꿈은 원문에서도 삭제하고 새로 입력한 줄바꿈은 편집 입력으로 반영한다. 여러 같은 줄바꿈이 연속된 경우에는 공통 앞뒤 구간을 기준으로 변경을 적용한다.

한 문항을 편집하는 중에는 입력 컴포넌트의 종류를 유지한다. 줄바꿈을 모두 지웠다는 이유로 textarea를 input으로 교체해 포커스나 한글 입력을 끊지 않는다. 저장 후 새로 열었을 때 줄바꿈이 없으면 한 줄 입력으로 열 수 있다. Enter를 시험 제출 단축키로 연결하지 않는다.

화면 검증은 실제 자료와 다른 가상 자료·별도 DB·별도 앱 식별자로 수행했다. 사용 중인 release 창을 종료하거나 평소 개발/release DB에 검증용 시험을 만들지 않았다. 한글 문자 삽입은 확인했지만 실제 한글 IME 연속 조합·후보 선택은 별도 확인이 필요하다. 붙여 넣은 줄바꿈의 편집 구간 처리는 자동 테스트로 확인했으며 실제 클립보드 붙여 넣기는 미확인이다.

## 확장 1 진행 상태

기초 문항은 사용자 방향에 따라 오답노트에 수동 추가하고 기존 오답 출제로 복습하도록 정리했다. 서술형 참고 답안의 4단어 제한 제외와 초기 평가의 개수 표시도 사용자 확정을 반영했다. [기초 학습과 사용자 평가 화면 초안](../화면흐름/07_기초학습과사용자평가.md)을 작성했으며 복습·정정·상태와 순번의 세부 정책은 별도 검토한다. 확정되지 않은 제안까지 사용자 결정으로 승격하지 않는다.

손상 기록의 기본 열 격리와 재계산 정책은 [확장 2](12_학습방식확장계획.md)에 남아 있다. 이번 보완이 해당 결함이나 서술형 구현을 완료한 것은 아니다. 문서와 exe 갱신을 함께 수행하며 commit·push는 하지 않는다.

새 exe는 Window/artifacts/StudyApp-0.1.0-windows-x64-20261126T063733163Z/StudyApp.exe로 생성했다. 현재 사용 중인 기존 release 창은 종료하지 않았다. 이전 창을 정상 종료한 뒤 새 exe를 실행해야 새 버전이 열린다. 새 release 빌드와 파일 해시는 확인했으며 새 release 창의 직접 실행은 사용 중인 앱과의 충돌을 피하기 위해 수행하지 않았다.
