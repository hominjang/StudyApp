# Windows 학습 앱 구현 기술

상태: React·Tauri로 전환. 확인일: 2026-11-24.

| 영역 | 선택 | 역할 |
| --- | --- | --- |
| 화면 | React·TypeScript·CSS | 학습 자료 선택·시험 설정·입력·결과 표시 |
| 개발과 번들 | Vite·Node 24 | 개발 중 화면 서버와 배포용 정적 파일 생성 |
| Windows 앱 | Tauri 2·WebView2 | 번들된 웹 UI 실행과 Rust 명령 연결 |
| 학습 처리 | Rust의 application·domain 모듈 | 출제·완전 일치 채점·오답 집계 |
| 저장 | rusqlite와 SQLite | Rust에서 명시적 트랜잭션과 상태 조건 처리 |
| JSON | serde·serde_json | 공통 JSON 1.0과 명령 DTO 검증·직렬화 |
| 배포 | Tauri의 Windows 배포 구성 | WebView2와 자원을 포함하는 배포 절차 검증 |

화면은 [Tauri의 Vite 연결 방식](https://v2.tauri.app/start/frontend/vite/)을 사용한다. React가 SQL이나 정답 모델을 직접 읽지 않고 [Tauri invoke](https://v2.tauri.app/develop/calling-rust/)로 Rust 명령을 호출한다. 일반 웹 호스팅과 로그인 서버는 구성하지 않는다. 개발 서버는 개발 중에만 사용하며 앱에서는 로컬 번들을 연다.

## 환경 준비와 버전

시스템 Node는 12.19.1이다. 시스템 설치를 바꾸지 않고 공식 배포본의 SHA-256을 확인한 Node 24.22.3을 Git 제외된 `.tools`에 준비했다. Window/.node-version과 package.json, package-lock.json으로 웹 환경과 패키지 버전을 기록한다.

2026-11-25에 Rust MSVC 1.100.0·Microsoft C++ Build Tools 2022·Windows SDK 10.0.26100.0을 준비하고 Windows 실행과 Rust 테스트를 확인했다. Rust는 .tools에 설치하고 rust-toolchain.toml로 버전을, Cargo.lock으로 의존성을 기록한다. 새 환경은 [Tauri 공식 선행 조건](https://v2.tauri.app/start/prerequisites/)에 따라 C++ 도구·SDK·Rust·WebView2를 준비한다.

기존 WPF·.NET 구현 선택을 대체한다. Android의 기술은 정하지 않으며 공통 데이터와 학습 규칙은 유지한다.

## 구현 범위

현재는 Windows 앱에서 자료 등록·시험·채점·결과 저장·자동 저장과 재개·기록 조회·오답 우선/오답만 출제를 구현했다. 자료 교환과 백업·복구가 다음 단계다. 브라우저 미리보기는 실제 자료·기록을 조회하거나 채점하지 않는다. 완료 범위와 검증 결과는 [기록과 오답 재학습 결과](../작업계획/10_기록조회와오답재학습.md)를 따른다.

자료·기록은 기존 `%LOCALAPPDATA%/StudyApp`에 보관하도록 구현한다. Git에서 제외한 실제 자료를 frontend src나 public, 배포 번들 코드에 직접 넣지 않는다. [데이터 관리 원칙](<../../공통 개발 문서/개발원칙/01_실제데이터와Git관리.md>)을 따른다.

2026-11-26에 Windows x64 release exe와 초기 자료의 실행 폴더 생성을 추가했다. 웹 UI는 실행 파일에 포함하고 자료는 exe 옆 initial-data에서 읽는다. 개발 서버 없이 실행·종료·재실행을 확인했으며, installer·서명·다양한 Windows 환경 검증은 남아 있다. [실행 파일 안내](../작업계획/11_Windows실행파일.md)
