# Windows 학습 앱 구현 기술

상태: 구현 기준 선정·코드와 빌드 검증 전. 확인일: 2026-11-24.

| 영역 | 선택 | 선택 이유 |
| --- | --- | --- |
| 언어와 실행 환경 | C#과 .NET 10 LTS | Windows 앱과 학습 처리·저장 코드를 같은 언어로 구성 |
| 화면 | WPF, XAML, MVVM | 문항·입력·번호 목록과 상태 표시를 바인딩하고 화면 로직 분리 |
| 저장 | Microsoft.Data.Sqlite 10.0 계열과 명시적 SQL | 기존 SQLite 설계의 트랜잭션과 상태 조건을 코드에서 직접 표현 |
| 자료 파일 | System.Text.Json | 준비된 JSON 1.0을 DTO로 읽고 명시적으로 검증 |
| 의존성 조립 | Desktop의 AppBootstrapper에서 생성자 주입 | 초기 세 프로젝트의 객체와 수명을 한 곳에서 구성 |
| 배포 | Windows x64용 self-contained 폴더와 ZIP | 런타임을 포함한 앱 폴더를 배포하고 사용자 DB를 별도 보존 |

WPF는 Windows에서 실행하는 .NET 화면 기술이다. .NET 10의 LTS 분류와 지원 상태는 [공식 지원 정책](https://dotnet.microsoft.com/en-us/platform/support/policy), 화면 기술은 [WPF 개요](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/overview/)에서 확인했다. 프로젝트 상황에 맞춘 선택이며 사용자 요구에 특정 프레임워크가 포함됐다는 뜻은 아니다.

## 개발 환경과 버전 고정

현재 확인된 SDK는 `5.0.400`, 운영체제 빌드는 `10.0.26300`, OS 아키텍처는 x64다. .NET 10 SDK의 설치와 새 프로젝트 빌드는 아직 진행하지 않았다. 환경 준비 후 `dotnet --info`와 WPF 기본 창으로 호환성을 확인한다.

Desktop은 `net10.0-windows`, Core와 Infrastructure는 `net10.0`을 사용한다. SDK는 설치·검증한 정확한 10.0 SDK 버전을 `global.json`에 기록한다. NuGet 패키지도 복원 확인 후 정확한 버전과 잠금 파일로 고정한다. `10.0` 계열 표기는 패키지의 임의 최신 버전 자동 사용을 뜻하지 않는다.

초기 화면은 작은 `ViewModelBase`와 `AsyncCommand`로 바인딩·중복 실행 방지를 제공한다. 별도의 MVVM 프레임워크나 ORM은 초기 의존성에 넣지 않는다.

## 실행 범위

사용자는 앱을 실행해 바로 자료를 선택한다. 가입·로그인 화면, 계정 서버와 인증 API를 구현하지 않는다. 최초 생성한 로컬 `learner_id`는 기록을 구분하는 내부 값이며 사용자가 입력하는 계정이 아니다.

자료와 기록은 `%LOCALAPPDATA%/StudyApp/`에 보관한다. 패키지의 JSON은 최초 등록과 명시적인 자료 갱신의 입력이다. 앱이 실행 중 외부 원문에 접속하거나 문제를 자동 생성하지 않는다.

프로젝트 책임은 [코드 구성](01_코드구성과의존성.md), DB 실행 방식은 [저장소 접근](04_저장소접근과트랜잭션.md), 배포 산출물은 [빌드와 검증](10_빌드배포와검증.md)을 따른다.
