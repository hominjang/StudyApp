# 시험 진행 자동 저장과 복구

상태: 자동 저장·저장 후 나가기·창 종료·재개 구현. 가상 자료의 실제 Windows 앱에서 저장 오류·정상 종료·강제 종료와 제출 처리 재개를 검증했다. [수행 결과](../작업계획/09_자동저장과시험재개.md)

## 저장 시점

- 답변이나 현재 위치가 바뀐 뒤 500ms 동안 추가 변경이 없으면 저장을 요청한다.
- 계속 입력하는 중에도 최대 2초마다 최신 상태의 저장 요청을 보낸다. 실제 완료 시점은 성공한 COMMIT으로 구분한다.
- 문항 이동과 저장 후 나가기 및 정상 창 닫기, 최종 제출에서는 최신 상태를 즉시 저장한다.

## 오래된 저장 방지

시험을 복원하면 저장된 `revision`부터 편집 버전을 시작하고, 입력이나 위치 변경마다 1씩 늘린다. 요청에는 시험 ID와 편집 버전 및 해당 시점의 답변·위치를 함께 담는다.

저장은 진행 중 시험이고 요청 버전이 저장 버전보다 클 때만 적용한다. 더 오래된 요청은 무시하며 같은 버전의 동일 내용은 중복 저장하지 않는다. 같은 버전에 다른 내용이 오면 충돌을 안내한다.

제출된 시험에는 늦게 도착한 자동 저장을 적용하지 않는다. 화면의 저장 완료 표시는 현재 편집 버전까지 저장된 경우에만 사용한다. 요청과 완료 알림은 해당 시험에만 적용한다.

## 중단과 재개

진행 중 시험은 저장된 위치와 답변으로 이어 푼다. 제출 후 처리 중인 시험은 입력을 잠근 채 채점과 저장을 재개한다. 완료된 시험은 결과를 조회한다.

읽기 실패나 데이터 불일치는 기록 없음과 구분하고 재시도를 안내한다. 기존 DB와 기록을 삭제하거나 새 시험으로 대체하지 않는다. 저장 실패 시 입력은 유지하고 마지막 성공 상태와 미저장 상태를 구분한다.

동일한 로컬 프로필의 편집은 앱의 한 실행 인스턴스에서 처리한다. 저장 큐와 버전 검사는 지연된 저장 요청이 최신 답변을 덮는 상황에도 적용한다. 재시도는 같은 시험과 버전의 상태에서 이어간다.
