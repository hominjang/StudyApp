# 학습 기록 저장과 조회

상태: 초기 구현 기준. 데이터 정의는 [학습 기록](<../../공통 개발 문서/상세설계/데이터/02_학습기록.md>)을 따른다.

| 논리 테이블 | 키와 제약 |
| --- | --- |
| `learners` | `learner_id` 기본 키. 초기 프로필을 보존 |
| `exams` | `exam_id` 기본 키, 사용자 외래 키, 상태·편집 버전·완료 순번 |
| `exam_responses` | 시험·위치 복합 기본 키, 시험·묶음·문항 조합의 유일 제약 |
| `item_progress` | 사용자·묶음·문항 복합 기본 키, 현재 오답 대상과 연속 정답 수 |

응답은 시험에 강하게 연결한다. 응답에 보관한 원본 묶음·문항 ID에는 원본 제거 시 시험까지 삭제하는 외래 키 연쇄 삭제를 두지 않는다. 문항 학습 상태의 원본 참조도 같은 기준이다.

시험 상태는 `in_progress`, `submitted`, `completed`다. 최종 제출 전 응답은 `ungraded`이며 완료된 시험에는 미채점 응답이 없어야 한다.

## 생성과 진행 저장

시험 생성 시 설정과 자료명 및 모든 문항의 질문·대표 정답·허용 표기를 함께 저장한다. 전체 저장이 성공해야 시험 화면에 진입한다.

진행 중 저장은 답변 원문과 현재 위치 및 편집 버전만 갱신한다. 출제 문항과 순서 및 정답 기준은 유지한다. 최종 제출 상태부터는 답변 변경을 허용하지 않는다.

## 완료와 조회

판정 결과와 시험 완료 및 영향받은 문항 학습 상태는 [완료 처리](02_1_완료처리와중복방지.md)에 따라 함께 확정한다. 조회만으로 상태를 갱신하거나 정답 횟수를 늘리지 않는다.

완료된 기록은 수정·삭제 기능을 초기 버전에서 제공하지 않는다. 재학습은 새 시험으로 남긴다. 데이터 파일의 재가져오기와 앱 재실행이 사용자 식별자를 바꾸거나 기록을 초기화하지 않게 한다.
