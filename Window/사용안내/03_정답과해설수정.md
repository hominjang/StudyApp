# 자료 학습에서 정답·해설 수정하기

작성일: 2026-11-27. 메뉴 순서는 **자료 학습 → 시험 시작 → 시험 기록 → 자료 추가**다.

1. **자료 학습**에서 고칠 문항을 찾고 **정답·해설 수정**을 누른다.
2. 단답형은 대표 정답·허용 표기를, 서술형은 참고 답안·핵심 내용을 수정한다. 해설도 추가·수정하거나 비울 수 있다.
3. **수정 저장**을 누른다. 저장 후 같은 페이지의 최신 내용을 다시 보여준다.
4. 바꾸지 않으려면 **편집 취소하고 최신 자료 보기**를 누른다.

단답형 정답과 각 허용 표기는 4단어 이하이며 빈 값·앞뒤 공백·줄바꿈을 허용하지 않는다. 허용 표기는 항목마다 입력하고 불필요한 항목은 **제외**한다. 서술형 참고 답안과 핵심 내용은 비울 수 없다. 문항 유형과 질문은 이 편집 화면에서 바꾸지 않는다.

수정은 현재 앱의 자료에 저장된다. 앞으로 새로 시작할 시험에 반영하며 이미 시작한 시험의 정답·답변·판정과 오답/연속 정답 기록은 그대로 유지한다. 가져왔던 JSON 파일은 자동으로 수정하지 않는다. 이전 JSON을 다시 가져오면 자료가 다시 갱신될 수 있으므로 미리보기를 확인한다.

편집 중에는 다른 메뉴·검색·페이지로 이동하지 않는다. 창을 닫으려면 먼저 저장하거나 편집을 취소한다. 저장 결과를 확인하지 못하면 입력을 바꾸지 않고 **같은 요청으로 다시 저장**한다. 다른 곳에서 자료가 바뀌었다는 안내가 나오면 편집 취소 버튼으로 최신 자료를 불러온 뒤 수정한다.

자료 추가의 파일 선택·양식·취소 버튼은 **내용 확인**과 같은 테두리·모서리·글자 크기/높이를 사용한다. 실제 적용 버튼은 같은 모서리/글자 크기로 주요 작업 색상을 유지한다. 구현·검증 결과는 [메뉴와 자료 편집](../작업계획/20_메뉴와자료편집.md)에 기록한다.
