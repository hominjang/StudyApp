# 질문과 답으로 자료 학습하기

작성일: 2026-11-27. 자료 학습 기능이 포함된 새 `StudyApp.exe`에서 사용한다.

1. 왼쪽 메뉴에서 **자료 학습**을 선택한다.
2. **학습할 자료**에서 전체 자료 또는 원하는 자료 하나를 고른다.
3. 질문 아래에 함께 나오는 정답을 읽는다. 단답형은 대표 정답·허용 표기, 서술형은 참고 답안·핵심 내용이 표시된다. 해설이 있으면 함께 표시된다.
4. 필요한 용어는 **질문 검색**에 입력하고 **검색**을 누른다. 질문 내용만 검색하며 답안·사용자 답변은 검색하지 않는다.
5. 20문항씩 읽고 **이전 페이지 / 다음 페이지**로 이동한다.

이 화면에는 시험 답변 입력·제출·채점이 없다. 읽기만 해서는 시험 기록, 판정, 연속 정답 횟수와 오답 대상이 바뀌지 않는다. 시험 설정도 바꾸지 않는다. 시험을 풀고 싶으면 **시험 시작**으로 이동한다. 시험 진행 중에는 먼저 **저장 후 나가기**를 선택한다.

각 문항의 **정답·해설 수정**으로 현재 자료를 고칠 수 있다. 저장한 내용은 새 시험에만 반영한다. 자세한 순서는 [정답·해설 수정 안내](03_정답과해설수정.md)를 따른다.

현재 등록된 활성 문항을 보여주므로 자료를 갱신하면 이후 열람에 반영된다. 과거 시험의 질문·정답 스냅샷과는 구분한다. 읽던 위치·검색 조건의 재실행 후 복원은 제공하지 않는다.

기존 단답형 저장소에서도 바로 사용할 수 있으며 DB 전환은 필요하지 않다. 추가 자료를 읽으려면 [자료 추가 안내](01_문제자료추가.md)를 따른다. 검사 결과와 새 실행 위치는 [자료 학습 구현 결과](../작업계획/19_질문답자료학습.md)에서 확인한다.
