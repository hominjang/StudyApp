# 배포 앱에 문제 자료 추가하기

작성일: 2026-11-27. 자료 추가 기능이 포함된 새 실행 폴더의 `StudyApp.exe`를 사용한다. 이전 exe에는 이 메뉴가 없다. 개발 도구나 앱 재빌드 없이 JSON 자료를 가져올 수 있다.

## 추가 순서

1. 앱 왼쪽에서 **자료 추가**를 연다.
2. **학습 파일 (필수)**에서 준비한 `learning.json`을 선택한다. 해설·기초 문항 연결 파일이 있으면 **보충 파일 (선택)**에 같은 묶음의 `supplement.json`도 선택한다.
3. **내용 확인**을 누르고 자료명·문항 수·새 자료/갱신 여부와 추가·변경·비활성화 수를 확인한다.
4. 새 묶음이면 **자료 추가**, 같은 자료 ID면 **갱신 적용**을 누른다. 시험 시작 화면으로 돌아오면 해당 자료가 선택되어 있다.

파일은 각각 UTF-8 JSON, 16 MiB 이하로 준비한다. `catalog.json`이나 원문 문서, 변환 보고서, 시험 기록, DB 파일은 선택하지 않는다. 형식 오류가 나오면 안내된 필드를 수정하고 다시 선택한다. 파일 내용은 외부로 전송하지 않고 내 PC에서 검증·저장한다.

## 자료 만들기

자료 추가 화면의 **단답형 양식 받기** 또는 **서술형 양식 받기**로 직접 작성한 가상 양식을 받고 내용을 바꿔 저장한다. 내려받은 양식은 사용자 자료가 아니며, 원문을 자동으로 문제로 바꾸는 기능은 아니다. 문항을 추가하려면 `items` 배열에 문항 객체를 추가한다.

| 항목 | 작성 기준 |
| --- | --- |
| 자료 ID `dataset_id` | 다른 자료와 다르게 정한다. 소문자 영문·숫자, 사이의 하이픈만 사용하고 1~64자 |
| 문항 ID `id` | 같은 자료 안에서 중복 없이 정한다. 같은 형식·길이 기준 적용 |
| 단답형 1.0 | `question`, 대표 `answer`, 선택적인 `accepted_answers`. 각 정답·허용 표기는 4단어 이하, 문자열 완전 일치 |
| 서술형 2.0 | `type: descriptive`, `question`, `reference_answer`, `key_points`. 제출 후 직접 평가하며 참고 답안에 4단어 제한 없음 |
| 혼합 자료 2.0 | 단답형도 `type: short_answer`를 명시하고 기존 단답형 필드를 작성 |

현재 저장소가 기존 DB 1이면 1.0 단답형만 추가할 수 있다. 신규 DB 2는 1.0과 2.0을 지원한다. DB 1에 2.0을 선택하면 안내 후 거부하며 기존 기록은 바꾸지 않는다. 기록을 삭제하거나 DB를 바꿔 전환하지 않는다. 기존 저장소 전환 기능은 별도 작업이다.

전체 필드와 보충 파일 형식은 [자료 형식과 DB 호환](../구현설계/확장/01_저장구조.md), [공통 학습 데이터](../../공통%20개발%20문서/상세설계/데이터/01_학습데이터.md)를 따른다.

## 기존 자료 갱신

같은 자료 ID는 새 묶음으로 중복 추가하지 않고 갱신한다. 갱신 파일의 문항 목록이 앞으로 출제할 전체 목록이 된다. 빠진 문항은 비활성화하므로 한 문항만 추가하려면 기존 문항도 파일에 함께 담는다. 질문·정답·순서가 바뀌어도 과거 시험의 문항·답변·판정 스냅샷과 학습 기록은 보존한다. 의미가 다른 새 문항은 새 문항 ID를 사용한다.

보충 파일을 생략하면 기존 보충 정보·기초 연결을 유지한다. 제공한 보충 항목은 해당 문항의 선택 정보 전체를 교체하고, 생략한 문항의 보충 정보와 생략/null인 묶음 메타데이터는 유지한다. 2.0 보충 파일을 제공하면 기초 연결 목록 전체를 교체하며, `learning_links`를 생략하거나 빈 배열로 주면 목록을 비운다. 1.0 보충 파일은 기존 기초 연결을 변경하지 않는다.

내용이 같으면 중복 저장하지 않는다. 선택한 시점의 파일 내용을 사용하므로 원본 파일을 편집했다면 **파일 선택**으로 다시 고른 뒤 **내용 확인**을 눌러야 변경본이 반영된다. 저장 결과를 확인하지 못했다는 안내가 나오면 같은 요청으로 재시도하고 성공 여부를 확인한다.

내보내기·별도 자료로 복제·백업·복구는 아직 앱 메뉴로 제공하지 않는다. 구현·검증 범위는 [자료 추가 결과](../작업계획/18_배포앱자료추가.md)에 기록한다.
